🏗 Fundamentos de Angular

Subcategoría Conceptos Clave Temas Relacionados Definición
🧩 Componentes @Component, Ciclo de vida @Input, @Output, @ViewChild Son las unidades básicas de la interfaz en Angular. Controlan la vista y la lógica asociada.
🏗 Encapsulación de Estilos ViewEncapsulation Scoped Styles, Shadow DOM Permite controlar cómo los estilos afectan los componentes.
🎨 Directivas ngIf, ngFor, ngClass, ngStyle Directivas estructurales y de atributo Son instrucciones que modifican la estructura o apariencia del DOM.
🔗 Data Binding Property Binding, Event Binding, Two-Way Binding (ngModel) Binding unidireccional y bidireccional Es la sincronización de datos entre el modelo y la vista.
🖼 Proyección de contenido @ContentChild, @ContentChildren Uso de <ng-content> para inyección de contenido dinámico Permite insertar contenido en un componente desde su padre.
🚀 Inyección de Dependencias @Injectable, @Inject, providedIn: 'root' Servicios, Injector Es un patrón de diseño que permite la reutilización de código y separación de responsabilidades.

📋 Formularios y Validaciones

Subcategoría Conceptos Clave Temas Relacionados Definición
📝 Formularios Reactivos FormGroup, FormControl, FormArray Formularios dinámicos y anidados Es un enfoque basado en programación reactiva para manejar formularios.
✅ Validaciones Validators.required, AsyncValidator Validaciones síncronas y asíncronas Son reglas aplicadas a los formularios para garantizar que los datos ingresados sean correctos.
🔄 ngModel Binding bidireccional Uso en formularios de plantillas Permite la sincronización de datos en formularios basados en plantillas.
🔧 FormBuilder Creación de formularios con FormBuilder Simplificación de estructuras complejas Es un servicio que facilita la creación de formularios reactivos.
📄 Manejo de Errores FormControl.errors, FormGroup.hasError Mensajes de error dinámicos Facilita el control de errores en formularios de manera programática.
🏗 Formularios Dinámicos FormArray, Dynamic Forms Creación de controles dinámicos Permite agregar o eliminar campos en tiempo de ejecución.

🔄 Manejo de Estado y Ciclo de Vida

Subcategoría Conceptos Clave Temas Relacionados Definición
🚀 Inicialización ngOnInit Lógica al montar un componente Es un hook del ciclo de vida que se ejecuta después de la inicialización del componente.
🔄 Cambio de Datos ngOnChanges Detección de cambios en @Input Se dispara cuando un valor en el @Input cambia.
🗑 Limpieza ngOnDestroy Eliminación de suscripciones y recursos Se ejecuta antes de que Angular destruya el componente.
⏳ Otros Hooks ngAfterViewInit, ngAfterContentInit Uso en carga de vistas y contenido proyectado Son eventos que se disparan después de la renderización de la vista o el contenido.
💾 Manejo de Estado Global RxJS, BehaviorSubject, NgRx, Redux Centralización del estado de la aplicación Permite compartir datos entre componentes sin relación directa.

🗺 Ruteo y Navegación

Subcategoría Conceptos Clave Temas Relacionados Definición
🏠 Navegación Router, RouterLink Definición de rutas, parámetros dinámicos Es el sistema de enrutamiento que permite navegar entre vistas.
🔒 Protección de rutas CanActivate, CanDeactivate Route Guards para autenticación y permisos Son funciones que controlan el acceso a ciertas rutas.
🗂 Carga diferida loadChildren Implementación de Lazy Loading Permite cargar módulos solo cuando son necesarios.
🔄 Resolves Resolve en rutas Precarga de datos antes de navegar Son funciones que obtienen datos antes de que se active una ruta.
📡 Manejo de Parámetros ActivatedRoute, queryParams Parámetros en la URL Permite extraer datos de la URL para personalizar vistas.

🔌 HTTP, Servicios e Interceptores

Subcategoría Conceptos Clave Temas Relacionados Definición
🌐 Peticiones HTTP HttpClient, HttpParams, HttpHeaders Métodos GET, POST, PUT, DELETE Es el servicio de Angular para realizar peticiones HTTP a servidores.
🔄 Interceptores HttpInterceptor Modificación global de peticiones HTTP Permite modificar o interceptar solicitudes HTTP antes de que lleguen al servidor.
📦 Servicios @Injectable, Inyección de Dependencias Uso de providedIn: 'root' Son clases reutilizables que encapsulan lógica de negocio.
⚡ Manejo de Errores HTTP catchError, retry, throwError Control centralizado de errores Maneja errores en peticiones HTTP de manera eficiente.
