Set 1: Angular Style Encapsulation - Source Code Examples

  1. What is style encapsulation in Angular?

    It controls how styles defined in a component affect the component’s template and other parts of the app.

    @Component({
  styleUrls: ['./my.component.css'],
  encapsulation: ViewEncapsulation.Emulated
})
  2. What are the ViewEncapsulation options?

    Emulated, None, and ShadowDom.

    import { ViewEncapsulation } from '@angular/core';
  3. What does Emulated encapsulation mean?

    Styles are scoped to the component using generated attributes (default).

    encapsulation: ViewEncapsulation.Emulated
  4. What does None encapsulation mean?

    Styles are global and not scoped to the component.

    encapsulation: ViewEncapsulation.None
  5. What does ShadowDom encapsulation mean?

    Uses native Shadow DOM for real encapsulation.

    encapsulation: ViewEncapsulation.ShadowDom
  6. How to scope styles to a component?

    Use Emulated or ShadowDom encapsulation and styleUrls/styles.

    @Component({
  selector: 'app-sample',
  styleUrls: ['./sample.component.css'],
  encapsulation: ViewEncapsulation.Emulated
})
  7. Can styles leak with ViewEncapsulation.None?

    Yes, styles will affect other components globally.

    // Use caution with ViewEncapsulation.None
  8. How to style elements from parent to child component?

    Use global styles or None encapsulation if needed.

    /* styles.css */
app-child h1 { color: red; }
  9. Is Shadow DOM supported in all browsers?

    Modern browsers support it; fallback to Emulated if not available.

    encapsulation: ViewEncapsulation.ShadowDom
  10. Can you combine global and scoped styles?

    Yes, use global styles in styles.css and scoped in component files.

    /* styles.css */
body { margin: 0; }
/* my.component.css */
h1 { color: green; }
