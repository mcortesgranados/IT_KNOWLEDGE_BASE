Set 1: Angular Components - Basics

  1. What is an Angular component?

    An Angular component is a TypeScript class with a decorator @Component that controls a portion of the view and associated logic.

    @Component({
  selector: 'app-example',
  template: '
    Hello from component!
    '
})
export class ExampleComponent {}
  2. How do you define a component selector?

    The selector is defined in the @Component decorator and is used as a custom HTML tag to render the component.

    @Component({
  selector: 'app-header',
  templateUrl: './header.component.html'
})
  3. What does the templateUrl property do?

    It defines the path to an external HTML file that represents the component's template.

    @Component({
  selector: 'app-main',
  templateUrl: './main.component.html'
})
  4. What does the template property do?

    It allows you to define the component's template inline within the decorator.

    @Component({
  selector: 'app-inline',
  template: '
    Inline Template
    '
})
  5. What is the purpose of the styleUrls property?

    It allows linking to external CSS files to style the component.

    @Component({
  selector: 'app-styled',
  templateUrl: './styled.component.html',
  styleUrls: ['./styled.component.css']
})
  6. Can you use both template and templateUrl in a component?

    No, you should use either template or templateUrl, not both.

  7. How do you register a component in a module?

    You add it to the declarations array of the module.

    @NgModule({
  declarations: [ExampleComponent],
  imports: [CommonModule],
  bootstrap: [AppComponent]
})
export class AppModule {}
  8. How do you render a component in HTML?

    By using its selector as a tag in the template: <app-example></app-example>.

  9. How do you create a component using Angular CLI?

    Run the command: ng generate component component-name.

  10. Can components be nested in Angular?

    Yes, you can nest components by including a child component's selector in a parent component's template.

    <app-child></app-child>

Set 2: Component Lifecycle

  1. What is the lifecycle of an Angular component?

    The lifecycle includes creation, rendering, updating, and destruction. Angular provides hooks at each stage.

  2. What is the purpose of ngOnInit?

    It is called once after the first ngOnChanges and is used for component initialization.

    ngOnInit() {
  console.log('Component initialized');
}
  3. What does ngOnChanges do?

    It is called when any data-bound input property changes.

    ngOnChanges(changes: SimpleChanges) {
  console.log('Changes:', changes);
}
  4. When is ngOnDestroy triggered?

    When Angular destroys the component, typically used for cleanup like unsubscribing.

    ngOnDestroy() {
  console.log('Component destroyed');
}
  5. What is ngAfterViewInit used for?

    It is called after component’s view (and child views) has been initialized.

    ngAfterViewInit() {
  console.log('View initialized');
}
  6. What lifecycle hook is called before ngAfterViewInit?

    ngAfterContentInit is called before ngAfterViewInit.

  7. Can you implement multiple lifecycle hooks in one component?

    Yes, you can implement any combination of hooks based on your needs.

  8. How do you implement lifecycle hooks?

    By importing interfaces from @angular/core and implementing them in your class.

    export class MyComponent implements OnInit, OnDestroy {
  ngOnInit() {}
  ngOnDestroy() {}
}
  9. Why is ngOnInit preferred over the constructor for initialization?

    Because Angular has fully initialized inputs by the time ngOnInit runs, unlike the constructor.

  10. What is the execution order of lifecycle hooks?

    Constructor → ngOnChanges → ngOnInit → ngDoCheck → ngAfterContentInit → ngAfterContentChecked → ngAfterViewInit → ngAfterViewChecked → ngOnDestroy

Set 3: @Input and @Output

  1. What is @Input() in Angular?

    It allows data to be passed from a parent component to a child component.

    @Input() title: string;
  2. What is @Output() in Angular?

    It is used to emit events from a child component to its parent.

    @Output() clicked = new EventEmitter<void>();
  3. How do you bind a value using @Input?

    Use property binding syntax in the parent component template.

    <app-child [title]="parentTitle"></app-child>
  4. How do you handle an event using @Output?

    Bind the event in the parent component template using event binding syntax.

    <app-child (clicked)="onChildClicked()"></app-child>
  5. Can @Input and @Output be renamed?

    Yes, you can alias them using the decorator syntax.

    @Input('aliasName') propName: string;
@Output('aliasEvent') event = new EventEmitter();
  6. What is EventEmitter?

    A class that helps emit custom events in Angular using @Output.

    this.clicked.emit();
  7. Can you use @Input in a service?

    No, @Input is used only in components or directives.

  8. Is it mandatory to initialize @Output?

    Yes, it should be initialized with a new EventEmitter to emit events.

  9. Can you bind a method to @Output?

    No, you handle events with a method but cannot directly bind a method reference to @Output.

  10. Can a component have multiple @Input and @Output?

    Yes, you can define as many @Input and @Output properties as needed.

Set 4: @ViewChild

  1. What is @ViewChild in Angular?

    It allows you to access a child component, directive, or DOM element from a parent component class.

    @ViewChild(ChildComponent) child: ChildComponent;
  2. When is @ViewChild available in the lifecycle?

    It is set after ngAfterViewInit() lifecycle hook.

    ngAfterViewInit() {
  console.log(this.child);
}
  3. How do you use @ViewChild to access a DOM element?

    Use a template reference variable with @ViewChild.

    @ViewChild('myDiv') divRef: ElementRef;
...
<div #myDiv>Hello</div>
  4. What is ElementRef in Angular?

    It is a wrapper around a native DOM element that gives direct access to it.

    this.divRef.nativeElement.style.backgroundColor = 'yellow';
  5. What happens if the queried element isn't found with @ViewChild?

    The reference will be undefined.

  6. Can you access a child directive using @ViewChild?

    Yes, you can access directives as long as they are in the template.

  7. Can @ViewChild be used with dynamic components?

    No, use ViewContainerRef and ComponentFactoryResolver for dynamic components.

  8. How do you make sure @ViewChild updates when the view changes?

    Use { static: false } for dynamically created elements.

    @ViewChild('someRef', { static: false }) ref;
  9. What is the default value for the static option in @ViewChild?

    It is false in most cases.

  10. Can you use @ViewChild with multiple elements?

    Use @ViewChildren to access multiple elements or components.

    @ViewChildren('myRefs') divs: QueryList<ElementRef>;

Set 5: Component Communication

  1. How do Angular components communicate?

    They communicate using @Input, @Output, services, and shared state.

  2. What is parent to child communication?

    Passing data from parent to child using @Input.

    <child [data]="parentData"></child>
  3. How does child to parent communication work?

    Using @Output with EventEmitter.

    @Output() notify = new EventEmitter<string>();
this.notify.emit('message');
  4. How can siblings communicate in Angular?

    Use a shared service with BehaviorSubject or Subject.

    subject.next(value);
subject.subscribe(data => { ... });
  5. Can services be used for component interaction?

    Yes, services can manage shared state or emit data using observables.

  6. What is a shared service?

    A service injected into multiple components to share data or logic.

  7. What is the role of observables in communication?

    They allow components to reactively respond to changes in shared data.

  8. How can you unsubscribe from an observable?

    Store the subscription and call unsubscribe() in ngOnDestroy().

    subscription = observable.subscribe(...);
ngOnDestroy() {
  subscription.unsubscribe();
}
  9. How do template reference variables help in communication?

    They let parent access child component methods or properties via @ViewChild.

    <child #childComp></child>
@ViewChild('childComp') child;
  10. Can router parameters be used for communication?

    Yes, you can pass data through query or route parameters.

    this.route.snapshot.paramMap.get('id');

Set 6: Component Interaction Patterns

  1. What is a smart component?

    A component that handles business logic and interacts with services.

  2. What is a dumb component?

    A component focused only on UI; it receives inputs and emits outputs.

  3. When to use a shared module?

    To consolidate reusable components, directives, and pipes across the app.

  4. What are feature modules?

    Modules used to group components logically by functionality or features.

  5. Can one component use another component’s method?

    Yes, using @ViewChild to get a reference and call its method.

    @ViewChild(ChildComponent) child!: ChildComponent;
this.child.someMethod();
  6. How to share constants across components?

    Define constants in a separate TypeScript file and import them where needed.

  7. What is a singleton service?

    A service provided in root that has a single instance across the app.

  8. How does Angular DI (Dependency Injection) work?

    It injects services into components via constructors based on providers.

  9. Can two components share the same service?

    Yes, if the service is provided in root or in a shared module.

  10. What is an example of a reusable component?

    A button component with @Input for label and @Output for click.

    <app-button [label]="'Save'" (clicked)="saveHandler()"></app-button>

Set 7: View Encapsulation

  1. What is View Encapsulation in Angular?

    It determines whether styles defined in a component affect the entire application or only the component.

  2. What are the types of View Encapsulation?

    Emulated, ShadowDom, and None.

  3. Which is the default View Encapsulation mode?

    Emulated is the default.

  4. How to set View Encapsulation in a component? 
    @Component({
  encapsulation: ViewEncapsulation.None
})
  5. What is Emulated encapsulation?

    Angular adds scoped attributes to styles to apply them only to the component.

  6. What is None encapsulation?

    No encapsulation; styles can affect the entire application.

  7. What is ShadowDom encapsulation?

    Uses native Shadow DOM for true style encapsulation.

  8. Can we use global styles with encapsulated components?

    Yes, global stylesheets like styles.css can apply styles globally.

  9. Can encapsulated styles be overridden?

    Only with deep selectors like ::ng-deep or /deep/, though they are deprecated.

  10. When should we use ViewEncapsulation.None?

    When we need styles to be shared globally or when integrating third-party styles.

Set 8: Dynamic Components

  1. What are dynamic components in Angular?

    Components that are created and inserted into the DOM at runtime.

  2. How do you load a dynamic component?

    Using ViewContainerRef.createComponent().

  3. What is a ComponentFactoryResolver?

    A service used to create a component factory for a component (deprecated in Angular 13+).

  4. How to define an anchor for a dynamic component?

    Use @ViewChild with ViewContainerRef.

  5. Can you pass data to dynamic components?

    Yes, by accessing and assigning to the instance's input properties.

  6. How to destroy a dynamically created component?

    Use componentRef.destroy().

  7. Is it possible to insert multiple dynamic components?

    Yes, by calling createComponent() multiple times on the container.

  8. Do dynamic components participate in change detection?

    Yes, they are part of the Angular component tree once inserted.

  9. Can a dynamic component emit events?

    Yes, you can subscribe to its @Output events from the host.

  10. Why use dynamic components?

    They provide flexibility for rendering components based on user actions or configurations.

Set 9: Dynamic Components - Source Code Examples

  1. What are dynamic components in Angular?

    Components created and inserted at runtime using createComponent.

    // component-loader.component.ts
import { Component, ViewChild, ViewContainerRef } from '@angular/core';
import { HelloComponent } from './hello.component';

@Component({
  selector: 'app-component-loader',
  template: ''
})
export class ComponentLoaderComponent {
  @ViewChild('container', { read: ViewContainerRef }) container!: ViewContainerRef;

  ngAfterViewInit() {
    this.container.createComponent(HelloComponent);
  }
}
  2. How do you load a dynamic component?

    By referencing ViewContainerRef and using createComponent.

    this.container.createComponent(HelloComponent);
  3. What is a ComponentFactoryResolver?

    A resolver for older Angular versions (deprecated in Angular 13+).

    // Angular <13 example
constructor(private resolver: ComponentFactoryResolver) {}

ngAfterViewInit() {
  const factory = this.resolver.resolveComponentFactory(HelloComponent);
  this.container.createComponent(factory);
}
  4. How to define an anchor for a dynamic component?

    Using @ViewChild to access the ng-template.

    // HTML template


// Component
@ViewChild('dynamicAnchor', { read: ViewContainerRef }) anchor!: ViewContainerRef;
  5. Can you pass data to dynamic components?

    Yes, by setting input properties on the created component instance.

    const ref = this.container.createComponent(HelloComponent);
ref.instance.name = 'Manuela';
  6. How to destroy a dynamically created component?

    Call destroy() on the ComponentRef instance.

    const ref = this.container.createComponent(HelloComponent);
ref.destroy();
  7. Is it possible to insert multiple dynamic components?

    Yes, each call to createComponent() adds a new one.

    this.container.createComponent(HelloComponent);
this.container.createComponent(HelloComponent);
  8. Do dynamic components participate in change detection?

    Yes, once added to the view, they are managed by Angular's change detection.

    const ref = this.container.createComponent(HelloComponent);
ref.instance.name = 'Live Change';
  9. Can a dynamic component emit events?

    Yes. You can subscribe to its @Output emitters.

    ref.instance.clicked.subscribe(() => console.log('Clicked!'));
  10. Why use dynamic components?

    To load content conditionally or based on runtime logic.

    if (this.isLoggedIn) {
  this.container.createComponent(ProfileComponent);
} else {
  this.container.createComponent(LoginComponent);
}

Set 10: Content Projection & ng-content - Source Code Examples

  1. What is content projection in Angular?

    It is a pattern to insert external content into a component using <ng-content>.

    // card.component.html
<div class="card">
  <ng-content></ng-content>
</div>
  2. How do you project content into a component?

    Using <ng-content> in the component template.

    // usage
<app-card>
  <p>This is projected</p>
</app-card>
  3. How to use multiple slots in content projection?

    Use the select attribute on <ng-content>.

    // component.html
<ng-content select=".header"></ng-content>
<ng-content select=".body"></ng-content>
  4. What happens if no content is projected?

    The component still renders but with no inserted content.

    // still renders
<app-card></app-card>
  5. Can you combine content projection and inputs?

    Yes, you can use @Input and <ng-content> together.

    // card.component.ts
@Input() title: string = '';
  6. Is <ng-content> compiled statically or dynamically?

    It is compiled statically during render.

    // included at render time
<ng-content></ng-content>
  7. Can projected content have its own components?

    Yes, Angular will render them inside the host component.

    <app-card>
  <app-user-profile></app-user-profile>
</app-card>
  8. How to project content conditionally?

    Use *ngIf inside projected slots or on content tags.

    // parent component
<app-card>
  <p *ngIf="show">Conditional</p>
</app-card>
  9. Can you nest <ng-content>?

    No, Angular does not support nested <ng-content> tags directly.

    // Not supported
<ng-content>
  <ng-content></ng-content>
</ng-content>
  10. How to style projected content?

    Use ::ng-deep or expose slots with known class names.

    ::ng-deep .header {
  color: red;
}

Set 11: Angular Component Communication - Source Code Examples

  1. What are the primary ways components communicate in Angular?

    Via @Input(), @Output(), shared services, and ViewChild.

    // @Input example
@Input() data: string;

// @Output example
@Output() clicked = new EventEmitter();
  2. How does @Input() help with component communication?

    It allows data to flow from parent to child component.

    // parent.html
<child [data]="parentData"></child>

// child.ts
@Input() data: string;
  3. How does @Output() facilitate communication?

    It lets the child send data to the parent through events.

    // child.ts
@Output() notify = new EventEmitter<string>();
notify.emit('Hi parent!');
  4. What is a shared service for component communication?

    A singleton service shared across components to exchange data.

    // shared.service.ts
@Injectable({ providedIn: 'root' })
export class SharedService {
  message = new BehaviorSubject('default');
}
  5. How does a parent access a child method using @ViewChild?

    By referencing the child component and calling its public method.

    // parent.ts
@ViewChild(ChildComponent) child!: ChildComponent;
ngAfterViewInit() {
  this.child.sayHello();
}
  6. Can sibling components communicate directly?

    Not directly; they must use a shared parent or a shared service.

    // Sibling communication via service
sharedService.message.next('new data');
  7. What is EventEmitter in Angular?

    A class used by @Output() to emit custom events.

    @Output() customEvent = new EventEmitter<string>();
  8. How to use a service with observables for communication?

    By subscribing and pushing data via a Subject or BehaviorSubject.

    // in service
message = new BehaviorSubject('');

// in component
this.service.message.subscribe(msg => this.msg = msg);
  9. What is two-way binding in Angular?

    A combination of @Input() and @Output() with [(ngModel)].

    // component.html
<input [(ngModel)]="name" />
  10. How to handle complex data transfer between components?

    Use services with Subjects or strong-typed events.

    this.sharedService.updateData({ user: 'Manuela', role: 'admin' });

Set 12: Angular Pipes - Source Code Examples

  1. What is a pipe in Angular?

    A pipe is used to transform data in templates.

    {{ 1234.56 | currency:'USD' }}
  2. How do you create a custom pipe?

    Implement PipeTransform and use the @Pipe decorator.

    // capitalize.pipe.ts
@Pipe({ name: 'capitalize' })
export class CapitalizePipe implements PipeTransform {
  transform(value: string): string {
    return value.charAt(0).toUpperCase() + value.slice(1);
  }
}
  3. How to use a custom pipe in a template?

    Declare it in the module and use like built-in pipes.

    {{ 'manuela' | capitalize }}
  4. Can pipes accept parameters?

    Yes, parameters are passed using colon syntax.

    {{ 1234.56 | currency:'EUR':'symbol' }}
  5. What is a pure pipe?

    A pipe that Angular executes only when input data changes.

    @Pipe({ name: 'filterList', pure: true })
  6. What is an impure pipe?

    A pipe that runs every change detection cycle.

    @Pipe({ name: 'impureExample', pure: false })
  7. How to debug a custom pipe?

    Use console.log inside the transform method.

    console.log('Transforming:', value);
  8. Can you chain multiple pipes?

    Yes, use the pipe operator multiple times in a template.

    {{ birthday | date:'fullDate' | uppercase }}
  9. How does a pipe differ from a function?

    Pipes are optimized for use in templates and integrate with change detection.

    // Function version not reactive:
transform(value: string): string
  10. What is a common use case for the async pipe?

    To subscribe to Observables in templates automatically.

    {{ user$ | async }}

Set 13: Angular Change Detection - Source Code Examples

  1. What is change detection in Angular?

    It's the mechanism that updates the DOM when component data changes.

    // Triggered automatically after data change
this.title = 'New Title';
  2. How does Angular detect changes?

    It runs the change detection tree to compare old and new values.

    // Angular runs change detection on events, async ops, etc.
  3. What is the default change detection strategy?

    CheckAlways - Angular checks all components in the tree.

    @Component({ changeDetection: ChangeDetectionStrategy.Default })
  4. How can you optimize change detection?

    Use OnPush strategy and immutable data.

    @Component({ changeDetection: ChangeDetectionStrategy.OnPush })
  5. When should OnPush be used?

    When inputs are immutable and changes come via inputs or observables.

    @Input() user: User;
  6. How do you manually trigger change detection?

    Inject ChangeDetectorRef and call detectChanges().

    constructor(private cd: ChangeDetectorRef) {}
this.cd.detectChanges();
  7. What is markForCheck()?

    It tells Angular to re-check an OnPush component on the next tick.

    this.cd.markForCheck();
  8. How do Observables work with OnPush?

    Async pipe automatically triggers change detection when emitting new values.

    {{ data$ | async }}
  9. How does Angular handle events in OnPush strategy?

    Event handlers still trigger change detection in OnPush components.

    (click)="handleClick()"
  10. Why use immutable objects with OnPush?

    They help Angular detect changes by reference comparison.

    this.user = { ...this.user, name: 'Updated' };

Set 14: Angular Directives - Source Code Examples

  1. What are Angular directives?

    Directives are classes that add behavior to elements in Angular applications.

    @Directive({ selector: '[appHighlight]' })
  2. What are structural directives?

    They change the DOM layout by adding or removing elements.

    *ngIf, *ngFor, *ngSwitch
  3. How do attribute directives work?

    They change the appearance or behavior of DOM elements.

    @HostBinding('style.backgroundColor') bgColor;
  4. How to create a custom attribute directive?

    Use the @Directive decorator and implement logic in the class.

    @Directive({ selector: '[appCustom]' })
export class CustomDirective {
  constructor(el: ElementRef) {
    el.nativeElement.style.color = 'blue';
  }
}
  5. How to use a structural directive in a template?

    Use an asterisk before the directive name.

    Visible
  6. Can you pass values to directives?

    Yes, use input properties with the @Input decorator.

    @Input() set appHighlight(color: string) { ... }
  7. What is the purpose of HostListener?

    It listens to events on the host element.

    @HostListener('mouseenter') onMouseEnter() { ... }
  8. What is the difference between ngClass and [class] binding?

    ngClass allows dynamic multiple class bindings.

  9. How can you debug a directive?

    Use console.log inside lifecycle hooks like ngOnInit.

    ngOnInit() { console.log('Directive loaded'); }
  10. Can a directive manipulate the DOM directly?

    Yes, using ElementRef, but use Renderer2 for better practice.

    constructor(private el: ElementRef, private renderer: Renderer2) {
  renderer.setStyle(el.nativeElement, 'fontWeight', 'bold');
}

Set 15: Angular Dependency Injection - Source Code Examples

  1. What is dependency injection in Angular?

    It is a design pattern where objects are passed to a class rather than being created by the class itself.

    constructor(private service: MyService) {}
  2. How do you define a service in Angular?

    Use the @Injectable decorator on the class.

    @Injectable({ providedIn: 'root' })
export class MyService {}
  3. What is providedIn: 'root'?

    It registers the service with the root injector, making it a singleton across the app.

    @Injectable({ providedIn: 'root' })
  4. How to inject a service into a component?

    Use the constructor to declare it as a dependency.

    constructor(private myService: MyService) {}
  5. Can services be provided at component level?

    Yes, using the providers array in the component metadata.

    @Component({
  providers: [MyService]
})
  6. What is the Injector class?

    It's a low-level API for manual injection of dependencies.

    constructor(private injector: Injector) {
  const service = this.injector.get(MyService);
}
  7. How can you provide different implementations?

    Use the useClass or useValue providers in a module or component.

    providers: [{ provide: MyService, useClass: MyMockService }]
  8. What is the useFactory provider?

    It creates a service using a factory function.

    providers: [{ provide: MyService, useFactory: () => new MyService() }]
  9. What is the difference between a singleton and multiple instance service?

    Singletons are created once (e.g., with providedIn: 'root'), multiple instances can be created per component.

    // Singleton: providedIn: 'root'
// Multi-instance: provided in component
  10. How to inject a built-in Angular service?

    Same as custom services, e.g., Router, HttpClient.

    constructor(private router: Router, private http: HttpClient) {}
