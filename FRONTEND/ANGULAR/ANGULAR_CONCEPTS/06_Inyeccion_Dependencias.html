1. What is Dependency Injection?

Dependency Injection is a design pattern that allows separation of concerns, where objects do not create their own dependencies but instead have them provided externally.

class Service {
  constructor(private logService: LogService) {}
  
  execute() {
    this.logService.write('Executing service...');
  }
}

2. What does the @Injectable decorator do in Angular?

The @Injectable decorator in Angular marks a class as available for dependency injection. It tells Angular that this class should be injectable as a dependency in other components, services, etc.

@Injectable({
  providedIn: 'root'
})
export class LogService {
  write(message: string) {
    console.log(message);
  }
}
