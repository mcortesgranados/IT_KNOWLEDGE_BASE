Set 1: Angular Data Binding Questions (1-10)

  1. What is property binding in Angular?
    Property binding sets a property of an element to the value of a component property.
    [property]="expression" 
    <img [src]="imageUrl" />
  2. What is event binding in Angular?
    Event binding allows you to listen to events and call methods in the component.
    (event)="handler" 
    <button (click)="handleClick()">Click Me</button>
  3. What is two-way binding?
    Two-way binding synchronizes data between input and component using ngModel.
    [(ngModel)]="property" 
    <input [(ngModel)]="username" />
  4. How do you bind an input's value to a variable?
    Use property binding or two-way binding.
    <input [value]="userInput" />
<input [(ngModel)]="userInput" />
  5. How to bind a button's disabled attribute?
    <button [disabled]="isDisabled">Submit</button>
  6. Can you bind to custom properties in components?
    Yes, using @Input() in the child component. 
    // Parent
<app-child [title]="parentTitle"></app-child>
  7. How do you handle a custom event?
    Use @Output() in child and bind in parent. 
    // Parent
<app-child (notify)="onNotify()"></app-child>
  8. What is one-way data binding?
    Data flows from component to view only. 
    <p>{{ message }}</p>
<p [innerText]="message"></p>
  9. How to display dynamic class?
    <div [class.active]="isActive">Box</div>
  10. How to bind a style property?
    <div [style.backgroundColor]="bgColor">Color Box</div>

11. What is Property Binding in Angular?

Property binding is a one-way binding that allows values from the component to be reflected in the view.

Code:

<img [src]="imageUrl" alt="Image">
imageUrl = 'https://example.com/image.jpg';

12. How do you use Event Binding in Angular?

Event binding allows methods in the component to be triggered when a DOM event occurs, such as a click or keyboard entry.

Code:

    alert('Click event triggered!');
  }

13. What is Two-Way Binding in Angular?

Two-way binding allows changes in the view to reflect in the model and vice versa. It is typically used with ngModel.

Code:

<input [(ngModel)]="userName" placeholder="Enter your name">
<p>Hello, {{userName}}!</p>
userName = '';

14. What is the difference between one-way and two-way data binding?

One-way binding only reflects changes from the model to the view or vice versa, while two-way binding keeps both synchronized automatically.

One-way binding example:

<p>{{userName}}</p>
userName = 'John';

Two-way binding example:

<input [(ngModel)]="userName">
userName = 'John';
