Set 1: Angular Directives - Source Code Examples

  1. What is the purpose of the ngIf directive in Angular?

    The ngIf directive is used to conditionally include or remove an element from the DOM based on the value of an expression.

    <div *ngIf="isVisible">This is visible when 'isVisible' is true</div>
    export class AppComponent {
  isVisible = true;
}
  2. How does ngFor work in Angular?

    The ngFor directive is used to iterate over an array or a list and generate a view for each item in the collection.

    <div *ngFor="let item of items">{{ item }}</div>
    export class AppComponent {
  items = ['Item 1', 'Item 2', 'Item 3'];
}
  3. How can you apply classes dynamically using ngClass?

    The ngClass directive allows you to add or remove CSS classes dynamically based on the value of an expression.

    <div [ngClass]="{ 'active': isActive, 'inactive': !isActive }">This element changes class</div>
    export class AppComponent {
  isActive = true;
}
  4. What does ngStyle do in Angular?

    The ngStyle directive allows you to dynamically apply inline styles to an element based on the value of an expression.

    <div [ngStyle]="{ 'color': color, 'font-size': fontSize + 'px' }">Styled dynamically</div>
    export class AppComponent {
  color = 'red';
  fontSize = 16;
}
  5. Can you use ngIf and ngFor together in a single element?

    Yes, you can use both directives together to iterate over a collection conditionally.

    <div *ngIf="isVisible" *ngFor="let item of items">{{ item }}</div>

    Note: You need to wrap them in a <ng-container> if using them together on the same element.

    <ng-container *ngIf="isVisible">
  <div *ngFor="let item of items">{{ item }}</div>
</ng-container>
  6. How can you conditionally apply multiple CSS classes using ngClass?

    Use ngClass with an object that maps class names to boolean expressions to conditionally apply multiple classes.

    <div [ngClass]="{ 'highlight': isHighlighted, 'bold': isBold }">Text with conditional classes</div>
    export class AppComponent {
  isHighlighted = true;
  isBold = false;
}
  7. Can ngStyle be used to dynamically set properties like width and height?

    Yes, you can use ngStyle to dynamically set inline styles such as width, height, and others.

    <div [ngStyle]="{ 'width': width + 'px', 'height': height + 'px' }">Resizable div</div>
    export class AppComponent {
  width = 200;
  height = 100;
}
  8. How do you toggle visibility of an element using ngIf?

    Toggle the value of the expression bound to ngIf to show or hide the element.

    <div *ngIf="isVisible">This element is visible</div>
    export class AppComponent {
  isVisible = true;

  toggleVisibility() {
    this.isVisible = !this.isVisible;
  }
}
  9. Can you bind inline styles conditionally with ngStyle?

    Yes, you can conditionally apply inline styles based on the value of an expression.

    <div [ngStyle]="{ 'background-color': isRed ? 'red' : 'blue' }">Color changes based on condition</div>
    export class AppComponent {
  isRed = true;
}
  10. What is the syntax for using ngClass with an array of class names?

    Use ngClass with an array to apply multiple classes to an element.

    <div [ngClass]="['class1', 'class2']">Multiple classes applied</div>
    export class AppComponent {}

  4. What happens if you use ngFor on a non-iterable object?

    Using ngFor on a non-iterable object will result in an error. Ensure the object is iterable (like an array).

    <div *ngFor="let item of items">{{ item }}</div>
    export class AppComponent {
  items = ['Item A', 'Item B', 'Item C']; // Valid iterable object
}
  5. How can you dynamically change the styles of an element using ngStyle?

    You can dynamically change styles like background color, font size, etc., using the ngStyle directive with an object binding.

    <div [ngStyle]="{ 'background-color': backgroundColor, 'font-size': fontSize + 'px' }">Styled element</div>
    export class AppComponent {
  backgroundColor = 'lightblue';
  fontSize = 18;
}
  6. How can you display a default message when a list is empty with ngIf?

    You can use ngIf to check if the list is empty and display a default message accordingly.

    <div *ngIf="items.length === 0">No items available</div>
    export class AppComponent {
  items = [];
}
  7. Can you use ngIf with an else clause in Angular?

    Yes, ngIf can be used with an else clause to display an alternate template if the condition is false.

    <div *ngIf="isVisible; else elseBlock">Visible Content</div>
<ng-template #elseBlock>Not Visible</ng-template>
    export class AppComponent {
  isVisible = false;
}
  8. How do you use ngFor with trackBy for performance optimization?

    You can use trackBy with ngFor to improve performance by tracking the identity of items in the loop.

    <div *ngFor="let item of items; trackBy: trackById">{{ item.name }}</div>
    export class AppComponent {
  items = [{ id: 1, name: 'Item 1' }, { id: 2, name: 'Item 2' }];
  
  trackById(index: number, item: any): number {
    return item.id;
  }
}
  9. Can you bind multiple styles using ngStyle?
