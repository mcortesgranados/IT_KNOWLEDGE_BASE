1. What is content projection in Angular?

Content projection allows you to insert dynamic content into a component from its parent using <ng-content>.

<app-card>
  <p>This paragraph is projected into the card component.</p>
</app-card>

2. How do you project content in a component?

You use the <ng-content> tag inside the component's template where you want the projected content to appear.

<div class="card">
  <ng-content></ng-content>
</div>

3. How do you create a simple component with content projection?

Use <ng-content> inside the component’s template and insert content in the parent component.

// card.component.html
<div class="card">
  <ng-content></ng-content>
</div>
// app.component.html
<app-card>
  <p>Hello from parent!</p>
</app-card>

4. How do you use multiple slots with content projection?

Use select in <ng-content> to project content into multiple slots.

<div class="card">
  <ng-content select="[card-title]"></ng-content>
  <ng-content select="[card-body]"></ng-content>
</div>
<app-card>
  <h3 card-title>Title</h3>
  <p card-body>This is body content</p>
</app-card>

5. What is @ContentChild in Angular?

@ContentChild allows you to get a reference to a single projected content element or directive.

@ContentChild('contentRef') content: ElementRef;

ngAfterContentInit() {
  console.log(this.content.nativeElement.textContent);
}
<app-wrapper>
  <p #contentRef>Projected Content</p>
</app-wrapper>

6. What is @ContentChildren used for?

@ContentChildren allows access to multiple projected content elements or directives as a QueryList.

@ContentChildren('section') sections: QueryList<ElementRef>;

ngAfterContentInit() {
  this.sections.forEach(el => console.log(el.nativeElement.textContent));
}
<app-wrapper>
  <div #section>Section 1</div>
  <div #section>Section 2</div>
</app-wrapper>

7. Can you use ng-content with Angular forms?

Yes, you can project form elements and bind to them normally inside the projected slot.

<app-form-wrapper>
  <input [(ngModel)]="username" placeholder="Username" />
</app-form-wrapper>
<div>
  <ng-content></ng-content>
</div>

8. How does differ from property binding?

<ng-content> injects DOM content, while property binding transfers data into a component class property.

<app-banner>
  <h2>Title inside projection</h2>
</app-banner>
@Input() title: string; // ← This is not projection, it's binding

9. Can you nest content projection?

Yes. You can project content into a component that itself projects it into another component.

<app-wrapper>
  <app-card>
    <p>Nested content</p>
  </app-card>
</app-wrapper>
// wrapper.component.html
<div><ng-content></ng-content></div>

10. Can you apply styles to projected content?

Yes, projected content can be styled just like regular content in the parent or child component, depending on encapsulation.

// app.component.css
::ng-deep app-card p {
  color: red;
}
<app-card>
  <p>Styled content</p>
</app-card>

11. What lifecycle hook is best to access projected content?

You should use ngAfterContentInit() to safely access projected content using @ContentChild or @ContentChildren.

ngAfterContentInit() {
  console.log('Projected content available');
}

12. Can you project content into different parts of a component?

Yes, using multiple <ng-content select="..."> blocks with different selectors.

<ng-content select="[header]"></ng-content>
<ng-content select="[body]"></ng-content>
<ng-content select="[footer]"></ng-content>

13. How does Angular decide what content goes where with multiple ng-content?

Angular uses the CSS selector in select to match projected elements to the appropriate <ng-content> slot.

<ng-content select=".title"></ng-content>

14. Can you use content projection inside structural directives?

Yes, you can place <ng-content> inside elements using *ngIf, *ngFor, etc.

<div *ngIf="showContent">
  <ng-content></ng-content>
</div>

15. How can you detect changes in projected content?

You can implement AfterContentChecked to track changes, or use Observable patterns for custom logic.

ngAfterContentChecked() {
  console.log('Projected content checked');
}

16. Can you use @ContentChild to get a reference to a directive?

Yes. @ContentChild can be used with custom directives projected into a component.

@ContentChild(MyDirective) myDirective!: MyDirective;

17. What’s the difference between @ViewChild and @ContentChild?

@ViewChild queries elements inside the component’s own template. @ContentChild queries elements projected into the component.

18. Can projected content use local template variables?

Yes, local variables in the projected content behave like they do normally.

<app-wrapper>
  <input #username>
  <button (click)="alert(username.value)">Show</button>
</app-wrapper>

19. How do you access a DOM element in projected content?

Use @ContentChild with ElementRef to access DOM elements.

@ContentChild('projected') content: ElementRef;

ngAfterContentInit() {
  console.log(this.content.nativeElement.innerText);
}
<app-wrapper>
  <p #projected>Hello projected DOM</p>
</app-wrapper>

20. Can you reproject content in Angular?

Yes, content can be projected multiple levels deep (from grandparent to child, to grandchild).

// Grandparent
<app-grandparent>
  <p>Deep content</p>
</app-grandparent>

// Grandparent template
<app-parent><ng-content></ng-content></app-parent>

// Parent template
<div class="box"><ng-content></ng-content></div>

21. Can you pass content with Angular bindings to ng-content?

Yes, Angular expressions and bindings in projected content are evaluated in the context of the parent component.

// Parent component
<app-display>
  <p>{{ message }}</p>
</app-display>
// app.component.ts
message = 'Hello from parent';

22. Can ng-content accept components as content?

Yes, you can project child components into another component using <ng-content>.

<app-wrapper>
  <app-child></app-child>
</app-wrapper>
// wrapper.component.html
<ng-content></ng-content>

23. How to style projected content selectively?

You can apply styles to projected content using deep selectors or apply classes to parent elements.

::ng-deep .projected-style {
  color: blue;
  font-weight: bold;
}

24. Can projected content access data from the child component?

No, projected content runs in the parent’s context, so it can’t access child component variables directly.

25. Can the child component control what is projected?

No, the child component only defines <ng-content> placeholders. It doesn't control the content.

26. How do you access a specific DOM element inside projected content?

Use @ContentChild with a template reference variable.

@ContentChild('myDiv') myDiv!: ElementRef;

ngAfterContentInit() {
  this.myDiv.nativeElement.style.color = 'red';
}
<app-box>
  <div #myDiv>Important</div>
</app-box>

27. How to project default content when nothing is passed?

Use *ngIf or conditional rendering to show default content if nothing is projected.

<div *ngIf="hasContent; else defaultTpl">
  <ng-content></ng-content>
</div>
<ng-template #defaultTpl>
  <p>Default content</p>
</ng-template>

28. Can I access dynamic components through content projection?

Yes, but you must use @ContentChild with the component class or directive to interact with it.

@ContentChild(MyDynamicComponent) cmp!: MyDynamicComponent;

29. Is ng-content reactive to parent changes?

Yes, the projected content updates automatically when data in the parent changes.

// Parent component template
<app-box>
  <p>{{ counter }}</p>
</app-box>
// app.component.ts
counter = 0;
setInterval(() => this.counter++, 1000);

30. What happens if multiple elements match a single select in ng-content?

All matching elements are projected into that <ng-content> slot.

<ng-content select="div"></ng-content>
<app-wrapper>
  <div>One</div>
  <div>Two</div>
</app-wrapper>

31. Can I use ng-content inside an *ngFor loop?

Yes, you can wrap <ng-content> in a container and repeat it using *ngFor, although the projected content itself won’t be duplicated.

<div *ngFor="let item of items">
  <ng-content></ng-content>
</div>

32. How to check if any content was projected?

You can use @ContentChild with a template reference and conditionally render based on its presence.

@ContentChild('content') content?: ElementRef;
hasContent = false;

ngAfterContentInit() {
  this.hasContent = !!this.content;
}

33. Can I use ViewEncapsulation with ng-content?

Yes, but remember that <ng-content> content is styled by the parent, not the child.

@Component({
  selector: 'app-card',
  template: '<ng-content></ng-content>',
  encapsulation: ViewEncapsulation.Emulated
})

34. How do I pass multiple content sections to a component?

Use multiple <ng-content select="..."> blocks with different selectors in your template.

<app-layout>
  <div header>Header content</div>
  <p body>Main content</p>
</app-layout>
<ng-content select="[header]"></ng-content>
<ng-content select="[body]"></ng-content>

35. Can you use a directive with projected content?

Yes, directives can be added to projected elements and queried via @ContentChild or @ContentChildren.

<app-box>
  <div myDirective>Test</div>
</app-box>
@ContentChild(MyDirective) dir!: MyDirective;

36. What happens if no content is projected into ng-content?

The <ng-content> slot remains empty. You can provide fallback content using templates.

<ng-content *ngIf="hasContent; else fallback"></ng-content>
<ng-template #fallback><p>No content available</p></ng-template>

37. Can I reproject ng-content into another component?

Yes, nested components can pass projected content further down the hierarchy using <ng-content>.

38. What’s the best use case for ng-content?

Reusable layout components (cards, modals, panels) where dynamic content needs to be inserted by the parent.

39. Is ng-content required for every component?

No, only components that are designed to receive dynamic content need <ng-content>.

40. What’s the difference between transclusion in AngularJS and content projection in Angular?

Angular’s content projection replaces AngularJS transclusion and uses <ng-content> instead of special directives.

41. Can I conditionally render projected content in Angular?

Yes, by wrapping <ng-content> in a container element and using structural directives like *ngIf.

<div *ngIf="shouldDisplay">
  <ng-content></ng-content>
</div>

42. How do I apply styles only to projected content?

You can use a wrapper around <ng-content> and target it with CSS classes.

<div class="projected-wrapper">
  <ng-content></ng-content>
</div>
.projected-wrapper > * {
  font-style: italic;
}

43. What is the difference between @ContentChild and @ContentChildren?

@ContentChild gets the first matching projected element. @ContentChildren returns a QueryList of all matching elements.

44. How to project content into a modal component?

Use <ng-content> inside the modal’s template to allow dynamic inner content.

<app-modal>
  <p>This is the modal content</p>
</app-modal>
// app-modal.component.html
<div class="modal">
  <ng-content></ng-content>
</div>

45. Can I nest multiple ng-content inside a component?

Yes, multiple <ng-content> blocks can exist, especially with different selectors.

<ng-content select="[title]"></ng-content>
<ng-content select="[content]"></ng-content>

46. Can content projection be used in standalone components?

Yes, standalone components in Angular 14+ support content projection the same way as module-based components.

47. Can I project an ng-template?

You can pass <ng-template> into components using ngTemplateOutlet, not <ng-content>.

// Parent
<ng-template #myTpl><p>Hello Template</p></ng-template>
<app-viewer [template]="myTpl"></app-viewer>
// Viewer
<ng-container *ngTemplateOutlet="template"></ng-container>

48. Can I use projected content in reactive forms?

Yes, you can project form fields and bind them using formControlName from the parent context.

// Parent
<form [formGroup]="form">
  <app-form-wrapper>
    <input formControlName="name">
  </app-form-wrapper>
</form>

49. Can I query a projected component’s input value?

Yes, if the projected component has an input, use @ContentChild and read its property in ngAfterContentInit.

@ContentChild(ChildComponent) child!: ChildComponent;

ngAfterContentInit() {
  console.log(this.child.inputValue);
}

50. Can projected elements trigger child component events?

Yes, events inside projected content bubble to the component and can be handled with standard Angular event bindings.

<app-panel (click)="handleClick()">
  <button>Click me</button>
</app-panel>

51. Can you animate projected content?

Yes, you can apply Angular animations to containers wrapping <ng-content>, or to the projected content itself.

<div [@fadeIn]>
  <ng-content></ng-content>
</div>

52. How does lifecycle timing work with projected content?

@ContentChild and @ContentChildren become available after ngAfterContentInit.

ngAfterContentInit() {
  console.log(this.projectedElement);
}

53. How do I project SVG elements?

SVGs can be projected like normal HTML content.

<app-graphic>
  <svg><circle cx="50" cy="50" r="40" /></svg>
</app-graphic>
<ng-content></ng-content>

54. Can I project deeply nested content?

Yes, deeply nested HTML or component trees are fully supported with <ng-content>.

<app-wrapper>
  <section><div><p>Nested!</p></div></section>
</app-wrapper>

55. How to apply a directive only to projected content?

You can apply the directive in the parent component and read it with @ContentChild.

// Parent
<div highlight>Project me</div>
@ContentChild(HighlightDirective) highlight!: HighlightDirective;

56. Can ng-content project content based on component input?

Not directly. Use conditions and selectors with multiple <ng-content> blocks and toggle visibility.

<ng-content *ngIf="showHeader" select="[header]"></ng-content>

57. Can a component with content projection be standalone?

Yes, starting with Angular 14+, standalone components fully support content projection.

58. How do I restrict what kind of content can be projected?

Angular does not restrict projected content types, but you can use selectors and validations in the component logic.

59. How to remove projected content conditionally?

Use *ngIf to conditionally hide projected slots based on inputs or logic.

<div *ngIf="showContent">
  <ng-content></ng-content>
</div>

60. Can I project content into a directive instead of a component?

No, content projection works only inside component templates, not directive templates.

61. Can I combine ng-content with ng-template?

Yes, but they serve different purposes. Use <ng-template> for structural control, and <ng-content> for projection.

<ng-template [ngIf]="show">
  <ng-content></ng-content>
</ng-template>

62. How to project multiple types of content in a layout component?

Use multiple <ng-content> slots with CSS selectors to separate header, body, and footer sections.

<ng-content select="[header]"></ng-content>
<ng-content select="[body]"></ng-content>
<ng-content select="[footer]"></ng-content>

63. What happens if content matches multiple ng-content selectors?

It will only be projected into the first matching <ng-content> in the template.

64. How can I project a button into a custom dialog footer?

Use attribute selectors like [footer] for <ng-content> to isolate footer-specific projections.

<app-dialog>
  <button footer>Close</button>
</app-dialog>
<ng-content select="[footer]"></ng-content>

65. Can projected content use ViewChild or local template references?

No, projected content cannot be accessed by @ViewChild. Use @ContentChild instead.

66. Can I dynamically load projected content?

To insert dynamic content, use ngTemplateOutlet or create the component programmatically using ViewContainerRef.

67. Can a directive be aware it's inside projected content?

Yes, using Angular's DI system, the directive can check its parent or be queried by @ContentChild.

68. Can I project content into a tab component?

Yes, content for each tab can be projected and selected based on the active tab index.

<app-tabs>
  <div tab>Tab 1 content</div>
  <div tab>Tab 2 content</div>
</app-tabs>

69. How to hide unused projected content?

Use *ngIf to control visibility based on context (like current tab or step).

70. Can projected content be reactive?

Yes, forms, observables, and reactive components can be used in projected content just like in regular Angular templates.

71. Can I project a component multiple times in different places?

No, a DOM element or component can only exist in one place in the DOM tree. To render it in multiple places, use templates or duplication.

72. What is the role of ViewContainerRef in dynamic content projection?

ViewContainerRef allows you to insert components or templates dynamically, often used alongside ngTemplateOutlet.

73. Can projected content include event bindings?

Yes, events defined in projected content behave normally and can be handled by parent or child components.

<app-box>
  <button (click)="handleClick()">Click Me</button>
</app-box>

74. What happens if ng-content is not provided in a component?

If the component does not include <ng-content>, any inner content passed to it is ignored.

75. Can I use pipes inside projected content?

Yes, you can use Angular pipes just like in any normal template.

<app-panel>
  <p>{{ user.name | uppercase }}</p>
</app-panel>

76. How do I pass dynamic data into projected content?

You can pass data from the parent using interpolation or inputs in projected components.

77. What’s a real-world use case for content projection?

Creating reusable UI components like modals, tabs, cards, or tooltips where the content varies.

78. Can ng-content be used inside a directive?

No, <ng-content> is a component-level feature, not available inside directives.

79. What is the difference between <ng-content> and ng-template?

<ng-content> is used to project static content. <ng-template> is used to define reusable template blocks.

80. Can ng-content be nested inside ngIf or ngFor?

Yes, wrap <ng-content> in a container element and apply structural directives on that container.

<div *ngIf="isVisible">
  <ng-content></ng-content>
</div>

81. Can I pass content with *ngFor into ng-content?

Yes, the parent component can use *ngFor to generate content that is then projected into the child component.

<app-list>
  <div *ngFor="let item of items">{{ item }}</div>
</app-list>

82. How do I validate projected form fields?

You can define form controls in the parent and use Angular reactive form features to validate the projected fields.

<form [formGroup]="form">
  <app-field-wrapper>
    <input formControlName="email">
  </app-field-wrapper>
</form>

83. Can I use input/output bindings on projected components?

Yes, projected components can use @Input and @Output like any other Angular component.

84. Can I use multiple named slots in one component?

Yes, by using <ng-content select="..."> you can create multiple named slots for organized content.

<ng-content select="[title]"></ng-content>
<ng-content select="[body]"></ng-content>

85. How can I track changes in projected content?

Use @ContentChildren and subscribe to the changes Observable of the QueryList.

@ContentChildren(MyDirective) items!: QueryList<MyDirective>;

ngAfterContentInit() {
  this.items.changes.subscribe(() => this.updateView());
}

86. Can projected content contain another component with ng-content?

Yes, nested content projection works. Content can be passed down through multiple layers of components.

87. Can I create tabs using content projection?

Yes, each tab’s content can be projected into a component and displayed conditionally based on active index.

88. Can I project content dynamically using a service?

You can dynamically create and inject components using Angular’s ComponentFactoryResolver and ViewContainerRef.

89. Is ng-content supported in Angular standalone components?

Yes, Angular standalone components (v14+) support full content projection features.

90. Can I use content projection with lazy-loaded modules?

Yes, as long as the projected content is passed from the parent into the component, it will be rendered correctly even across module boundaries.

91. Can I use ng-content inside a modal component?

Yes, content projection is ideal for modals, where the content of the modal can be projected from the parent component.

<app-modal>
  <div class="modal-content">This is dynamic content</div>
</app-modal>

92. How can I handle multiple projections for a card component?

Use multiple <ng-content> tags with selectors to separate header, content, and footer.

<app-card>
  <div header>Card Header</div>
  <div content>Card Content</div>
  <div footer>Card Footer</div>
</app-card>
<ng-content select="[header]"></ng-content>
<ng-content select="[content]"></ng-content>
<ng-content select="[footer]"></ng-content>

93. Can ng-content be conditionally rendered?

You can conditionally render projected content by wrapping <ng-content> in an *ngIf or other structural directive.

<div *ngIf="isVisible">
  <ng-content></ng-content>
</div>

94. How can I project a component’s content into a dynamic list?

Use ngFor in the parent and pass the dynamically created content into the child component using <ng-content>.

<app-item *ngFor="let item of items">
  <ng-content>{{ item.name }}</ng-content>
</app-item>

95. How does content projection impact performance?

Content projection doesn't have a significant performance overhead, but be mindful of complex projections with many nested components.

96. Can I project Angular directives into child components?

Yes, you can project elements with directives applied, and the directives will work as expected in the child component.

<app-my-component>
  <div myDirective>This is projected content</div>
</app-my-component>

97. Can I project content dynamically from a service?

While you can't directly project content from a service, you can use a service to change the content dynamically by updating a component's input properties or using dynamic component loading techniques.

98. Can I use <ng-content> to project content in Angular animations?

Yes, you can use <ng-content> with Angular animations, but ensure you target the correct elements within the content projection.

99. How can I add validation to projected form fields?

Use Angular's form validation features. If you're projecting form fields, you can manage validations by passing FormControl via input bindings.

100. Can projected content be a component with a lifecycle hook?

Yes, the projected content can be any Angular component, and its lifecycle hooks will be triggered as expected.
