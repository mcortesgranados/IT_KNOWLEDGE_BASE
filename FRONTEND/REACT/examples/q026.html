What is lazy loading in React?

React Beginner Questions - Set 3

Split the bundle so a route or a heavy widget is downloaded on demand instead of at startup.

import { lazy, Suspense, useState } from 'react';
import { Routes, Route } from 'react-router-dom';

// The import only happens when the component first renders
const Reports = lazy(() => import('./pages/Reports'));

export default function App() {
  const [show, setShow] = useState(false);

  return (
    <>
      <button onClick={() => setShow(true)}>Open reports</button>
      <Suspense fallback={<p>Loading module…</p>}>
        {show && <Reports />}
      </Suspense>
      <Routes>
        <Route path="/reports" element={
          <Suspense fallback={<p>Loading…</p>}><Reports /></Suspense>
        } />
      </Routes>
    </>
  );
}

What to notice

  • `lazy` needs a default export; a named export needs `.then(m => ({ default: m.X }))`.
  • Every lazy component needs a `Suspense` boundary above it, or React throws.
  • The win is initial JS size; the cost is a small delay the first time it is used.
