What is the difference between class components and functional components?

React Beginner Questions - Set 12

Example

1
2
function A() { const [n] = useState(0); return <p>{n}</p>; }
class B extends Component { state = { n: 0 }; render() { return <p>{this.state.n}</p>; } }

What to notice

  • Same capabilities; hooks removed the lifecycle/`this` ceremony.
