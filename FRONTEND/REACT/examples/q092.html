How can you handle form data in React?

React Beginner Questions - Set 10

const [form, setForm] = useState({ email: '', age: '' });
const change = e => setForm(f => ({ ...f, [e.target.name]: e.target.value }));
<form onSubmit={e => { e.preventDefault(); send(form); }}>
  <input name="email" value={form.email} onChange={change} />
</form>

What to notice

  • One state object + one computed-name handler scales to any number of fields.
