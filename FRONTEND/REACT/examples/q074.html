What is the difference between useEffect and useCallback in React?

React Beginner Questions - Set 8

Example

1
2
3
4
5
// useEffect runs after render, for side effects
useEffect(() => { document.title = `${count} clicks`; }, [count]);

// useCallback returns a memoised function, for identity
const onClick = useCallback(() => setCount(c => c + 1), []);

What to notice

  • Different jobs: one is timing, the other is reference stability.
