What is an uncontrolled component in React?

React Beginner Questions - Set 5

The DOM keeps the value; you read it when you need it through a ref, typically on submit.

import { useRef } from 'react';

export default function Upload() {
  const fileRef = useRef(null);
  const commentRef = useRef(null);

  function handleSubmit(e) {
    e.preventDefault();
    const formData = new FormData();
    formData.append('file', fileRef.current.files[0]);
    formData.append('comment', commentRef.current.value);
    console.log([...formData.keys()]);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input type="file" ref={fileRef} />
      <textarea ref={commentRef} defaultValue="Optional comment" />
      <button type="submit">Send</button>
    </form>
  );
}

What to notice

  • File inputs are the classic case: their value cannot be set from React, so they are always uncontrolled.
  • `defaultValue` sets the initial value; `value` would make it read-only.
  • No re-render per keystroke, but no validation or conditional UI while typing either.
