How do you create a React application?

React Beginner Questions - Set 1

There is no code file for this one — the answer is a set of commands. Vite is the current default; Create React App is the legacy path the question was written against.

# Recommended today (Vite)
npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev

# The path the question refers to (Create React App, legacy)
npx create-react-app my-app
cd my-app
npm start

# Either way, you end up with this minimum
src/main.jsx      imports React and mounts <App />
src/App.jsx       the root component
index.html        contains <div id="root"></div>

What to notice

  • `npm run dev` serves with hot reload on Vite; CRA uses `npm start`.
  • Both need Node 18+ and a `package.json`; nothing about React itself changes between them.
  • CRA is no longer recommended for new projects, but you will still meet it in existing repositories.
