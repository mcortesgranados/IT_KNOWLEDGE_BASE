How can you use React's useState hook?

React Beginner Questions - Set 11

Example

1
2
3
const [open, setOpen] = useState(false);
setOpen(true);            // direct
setOpen(o => !o);         // safer: uses the previous value

What to notice

  • Never mutate the value you got back; always go through the setter.
