How do you handle dynamic class names in React?

function Badge({ tone, active }) {
  const cls = `badge badge--${tone}${active ? ' badge--active' : ''}`;
  return <span className={cls}>New</span>;
}

// or with an array, which reads better with several conditions
const cls = ['badge', `badge--${tone}`, active && 'badge--active']
  .filter(Boolean).join(' ');

What to notice

  • Template literals + `filter(Boolean)` cover nearly every case; `clsx` when it grows.
