class Clock extends Component {
  state = { now: Date.now() };
  render() {
    // must be pure: no side effects, no state writes
    return <time>{new Date(this.state.now).toISOString()}</time>;
  }
}

What to notice

  • `render` returns the description; React decides when and how often to call it.
