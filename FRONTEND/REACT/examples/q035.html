What is lifting state up in React?

React Beginner Questions - Set 4

Two siblings need the same value, so the state moves to their parent and travels down as props.

import { useState } from 'react';

function CelsiusInput({ value, onChange }) {
  return <input value={value} onChange={e => onChange(Number(e.target.value))} />;
}

function Fahrenheit({ celsius }) {
  return <p>{celsius * 9 / 5 + 32} °F</p>;
}

export default function Converter() {
  const [celsius, setCelsius] = useState(20);   // lives in the parent

  return (
    <div>
      <CelsiusInput value={celsius} onChange={setCelsius} />
      <Fahrenheit celsius={celsius} />
    </div>
  );
}

What to notice

  • The parent becomes the single source of truth; the children stay dumb and testable.
  • Below the parent, data flows down as props and events flow up as callbacks.
  • If it starts reaching too far down, that is the signal to switch to context or a state library.
