How can you use environment variables in a React project?

React Intermediate Questions - Set 10

Example

1
2
3
// .env  ->  VITE_API_URL=https://api.example.com
const base = import.meta.env.VITE_API_URL;   // CRA: process.env.REACT_APP_*
fetch(`${base}/users`);

What to notice

  • Only prefixed variables are exposed, and they are compiled into the bundle — never put secrets there.
