Who developed React?

React Beginner Questions - Set 1

There is no code that answers a history question, so the honest example is the one line you can run to see which version of React — and therefore which era of Meta's stewardship — you are on.

import { version } from 'react';

export default function About() {
  return (
    <p>
      React {version} — originally built at Facebook (now Meta),
      maintained in the open at github.com/facebook/react.
    </p>
  );
}

What to notice

  • Created at Facebook in 2011, open-sourced in 2013, maintained by Meta engineers together with the community.
  • `version` comes from the package itself, so this page can never claim the wrong number.
  • The licence is MIT — worth knowing before a legal review asks.
