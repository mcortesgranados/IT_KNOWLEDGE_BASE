What is the `useLayoutEffect` hook in React?

React Intermediate Questions - Set 3

Example

1
2
3
4
useLayoutEffect(() => {
  const h = box.current.getBoundingClientRect().height;
  setHeight(h);   // applied before the browser paints
}, []);

What to notice

  • Synchronous after DOM mutations; blocks paint, so keep it cheap.
