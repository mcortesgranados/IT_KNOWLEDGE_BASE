What is React Router?

React Beginner Questions - Set 3

Routing is not built into React; React Router maps URLs to components so the page changes without a full reload.

import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';

export default function App() {
  return (
    <BrowserRouter>
      <nav>
        <Link to="/">Home</Link> | <Link to="/users/7">User 7</Link>
      </nav>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/users/:id" element={<UserPage />} />
        <Route path="*" element={<NotFound />} />
      </Routes>
    </BrowserRouter>
  );
}

What to notice

  • `Link` intercepts the click; an `<a href>` would reload the whole app.
  • `:id` is read inside `UserPage` with `useParams()`.
  • The `*` route is the catch-all — without it unmatched URLs render nothing.
