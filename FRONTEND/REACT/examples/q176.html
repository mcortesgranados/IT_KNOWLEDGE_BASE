What is the difference between `map` and `forEach` in JavaScript?

React Intermediate Questions - Set 6

Example

1
2
items.map(i => i.id);        // returns a new array
items.forEach(i => log(i));  // returns undefined

What to notice

  • `map` for rendering lists; `forEach` only for side effects.
