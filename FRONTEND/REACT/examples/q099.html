What is the difference between functional components and class components in terms of performance?

React Beginner Questions - Set 10

Example

1
2
3
// Function components avoid the class instance and the bind allocation,
// and memo/useMemo give the same skipping power as PureComponent.
const Row = memo(({ n }) => <p>{n}</p>);

What to notice

  • Modern React ships function-component optimisations first; classes are not faster.
