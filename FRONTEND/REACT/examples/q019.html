What is the purpose of the useRef hook?

React Beginner Questions - Set 2

A ref is a mutable box that survives renders and never triggers one. This example uses it for both jobs a ref has.

import { useRef, useState } from 'react';

export default function Search() {
  const inputRef = useRef(null);      // DOM reference
  const rendersRef = useRef(0);       // mutable value, no re-render

  const [, forceRender] = useState(0);
  rendersRef.current += 1;

  return (
    <div>
      <input ref={inputRef} placeholder="Type here" />
      <button onClick={() => inputRef.current.focus()}>Focus</button>

      <p>Renders so far: {rendersRef.current}</p>
      <button onClick={() => forceRender(n => n + 1)}>Re-render</button>
    </div>
  );
}

What to notice

  • Changing `ref.current` does not re-render; changing state does. That is the whole difference.
  • Use it for DOM access, timers, previous values and any mutable object that rendering should ignore.
  • Do not read `ref.current` during render for values that affect the output — that breaks the rendering contract.
