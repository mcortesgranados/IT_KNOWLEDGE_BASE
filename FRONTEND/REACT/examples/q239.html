How can you debounce a function in React?

React Intermediate Questions - Set 11

Example

1
2
3
4
useEffect(() => {
  const t = setTimeout(() => search(q), 400);
  return () => clearTimeout(t);
}, [q]);

What to notice

  • Cleanup cancels the previous timer, which is what debouncing means in practice.
