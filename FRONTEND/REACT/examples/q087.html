What is the difference between useState and useReducer?

React Beginner Questions - Set 9

Example

1
2
const [count, setCount] = useState(0);                       // one value
const [state, dispatch] = useReducer(reducer, { count: 0 });  // many values, named actions

What to notice

  • Reducer wins when transitions are named and the next state depends on several fields.
