How does React’s `useState` hook work?

React Intermediate Questions - Set 2

Example

1
2
3
const [n, setN] = useState(0);
setN(n + 1);          // value captured at render time
setN(prev => prev + 1);  // always the latest value

What to notice

  • React stores state outside the component and re-renders with the new value.
