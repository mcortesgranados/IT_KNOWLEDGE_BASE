What is a state in React?

React Beginner Questions - Set 7

function Toggle() {
  const [on, setOn] = useState(false);   // remembered across renders
  return <button onClick={() => setOn(o => !o)}>{on ? 'ON' : 'OFF'}</button>;
}

What to notice

  • A plain `let` variable resets on every render; `useState` does not.
