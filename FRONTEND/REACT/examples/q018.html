What is the role of keys in React lists?

React Beginner Questions - Set 2

Keys are how React recognises an item across renders. Using the array index looks fine until items are reordered or removed.

import { useState } from 'react';

export default function TodoList() {
  const [todos, setTodos] = useState([
    { id: 'a1', text: 'Write tests' },
    { id: 'a2', text: 'Deploy' },
  ]);

  function removeFirst() {
    setTodos(prev => prev.slice(1));
  }

  return (
    <>
      <ul>
        {todos.map(todo => (
          <li key={todo.id}>{todo.text}</li>   // stable, unique, not the index
        ))}
      </ul>
      <button onClick={removeFirst}>Remove first</button>
    </>
  );
}

What to notice

  • With `key={index}`, removing the first item makes React reuse DOM nodes with the wrong content — input focus and state jump.
  • Keys must be unique among siblings, stable over time, and never derived from the loop position.
  • Keys are not props: the child cannot read `props.key`.
