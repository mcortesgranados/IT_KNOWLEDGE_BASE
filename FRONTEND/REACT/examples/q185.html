How can you handle forms in React?

React Intermediate Questions - Set 7

const [v, setV] = useState('');
<form onSubmit={e => { e.preventDefault(); submit(v); }}>
  <input value={v} onChange={e => setV(e.target.value)} />
</form>

What to notice

  • `preventDefault` first, then read state — otherwise the page reloads.
