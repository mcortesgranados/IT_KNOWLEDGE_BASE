Installation and First App

This page covers how to install FastAPI, run the development server, and understand the minimal "Hello World" application.

Installation

It is recommended to use a virtual environment:

python -m venv venv
# Windows
venv\Scripts\activate
# Linux / macOS
source venv/bin/activate

pip install "fastapi[standard]"

The [standard] extra installs Uvicorn (with uvloop/httptools), python-multipart for forms/files, and other commonly used packages. Alternatively, install only the minimum:

pip install fastapi uvicorn

First Application: main.py

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"Hello": "World"}

@app.get("/items/{item_id}")
def read_item(item_id: int):
    return {"item_id": item_id}

Running the Server

# Modern CLI (installed with fastapi[standard])
fastapi dev main.py

# Classic way with uvicorn
uvicorn main:app --reload
  • main:app means: module main.py, object app.
  • --reload restarts the server when code changes (development only, never in production).
  • Default address: http://127.0.0.1:8000. Interactive docs: http://127.0.0.1:8000/docs.

Anatomy of the App

  • FastAPI(): creates the application instance; all routes, middleware and events attach to it.
  • Path operation decorators (@app.get, @app.post, @app.put, @app.delete, ...): declare the HTTP method and path.
  • Path operation function: the Python function that runs; its return value is serialized to JSON by default.
  • Type hints (item_id: int) are not comments: FastAPI validates and converts the incoming string path segment to an int automatically, returning 422 if it fails.

Quick Questions and Answers

Q: What is the difference between uvicorn and FastAPI?

A: FastAPI is the framework (routing, validation, docs). Uvicorn is the ASGI server that actually accepts TCP connections and talks to the app. You need both: the server hosts the application.

Q: Why does uvicorn main:app --reload fail with "ModuleNotFoundError"?

A: The command must run from the directory containing main.py, or you must pass the full dotted path (e.g. app.main:app if the file is app/main.py).

Q: Should I use --reload in production?

A: No. It watches files and restarts constantly, wasting resources. In production run Uvicorn with workers (or use Gunicorn managing Uvicorn workers): uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4.

Conclusion

Getting a FastAPI app running takes three steps: install, create the app object with decorated functions, and start Uvicorn. The type hints in the function signature are what power validation and the automatic docs.
