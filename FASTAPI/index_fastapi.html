FastAPI Knowledge Base

FastAPI is a modern, fast (high-performance) web framework for building APIs with Python, based on standard type hints. Content is organized by level, following the same structure as the Kafka section.

Levels

  • Basic — 15 topics: from installation to routers, dependency injection, async and docs. All questions and answers (single page).
  • Intermediate — 12 topics: background tasks, security (OAuth2/JWT/scopes), SQLAlchemy, WebSockets, testing, settings, lifespan, responses, pagination and versioning.
  • Advanced — planned: async DB patterns, deployment (Docker/K8s), observability, caching, scaling and microservices.
