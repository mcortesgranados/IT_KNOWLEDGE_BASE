Declaración de Variables en PL/SQL: Tipos Básicos

Explicación

En PL/SQL, la declaración de variables es una parte esencial para almacenar datos temporales mientras se ejecuta el código. Los tipos de datos básicos más comunes en PL/SQL son:

  • NUMBER: Utilizado para almacenar números enteros y decimales.
  • VARCHAR2: Utilizado para almacenar cadenas de texto de longitud variable.

Sintaxis Básica

DECLARE
  v_variable_nombre NUMBER(5, 2); -- Declaración de número con 5 dígitos y 2 decimales
  v_variable_texto VARCHAR2(50); -- Declaración de cadena de texto con un máximo de 50 caracteres
BEGIN
  -- Código ejecutable
END;

Ejemplo de Declaración de Variables

DECLARE
    v_salario NUMBER(7, 2) := 3500.50;
    v_nombre VARCHAR2(50) := 'Angela';
BEGIN
    -- Imprimir variables
    DBMS_OUTPUT.PUT_LINE('Salario: ' || v_salario);
    DBMS_OUTPUT.PUT_LINE('Nombre: ' || v_nombre);
END;
/

Explicación del Código

v_salario: Es una variable del tipo NUMBER(7, 2), que puede almacenar números con hasta 7 dígitos en total, de los cuales 2 son decimales.

v_nombre: Es una variable del tipo VARCHAR2(50), que puede almacenar hasta 50 caracteres de texto.

Dentro del bloque BEGIN, se imprime el valor de ambas variables utilizando DBMS_OUTPUT.PUT_LINE.
