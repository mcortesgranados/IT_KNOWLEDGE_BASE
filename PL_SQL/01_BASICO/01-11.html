Cursores Simples en PL/SQL: Declaración y Uso

Los cursores en PL/SQL son mecanismos que permiten manejar el conjunto de resultados de una consulta SELECT. Los cursores simples se declaran para almacenar los datos recuperados y luego se procesan fila por fila.

A continuación se muestra un ejemplo básico de cómo declarar y utilizar un cursor simple en PL/SQL:

DECLARE
    CURSOR c_empleados IS
        SELECT nombre, salario FROM empleados;
    v_nombre empleados.nombre%TYPE;
    v_salario empleados.salario%TYPE;
BEGIN
    OPEN c_empleados;
    LOOP
        FETCH c_empleados INTO v_nombre, v_salario;
        EXIT WHEN c_empleados%NOTFOUND;
        DBMS_OUTPUT.PUT_LINE('Empleado: ' || v_nombre || ' - Salario: ' || v_salario);
    END LOOP;
    CLOSE c_empleados;
END;
/

En este código:

  • El cursor c_empleados se declara para seleccionar los nombres y salarios de la tabla empleados.
  • El cursor se abre con OPEN, se recuperan los datos fila por fila con FETCH, y se cierra con CLOSE.
  • El bucle LOOP itera sobre cada fila del conjunto de resultados hasta que no quedan más filas, momento en que c_empleados%NOTFOUND devuelve TRUE, y se sale del bucle.
Explicación del código PL/SQL: Cursor Simple: Un cursor simple se utiliza para recorrer un conjunto de filas recuperado por una consulta. Código ejemplo: El cursor c_empleados selecciona el nombre y salario de la tabla empleados, y luego se itera sobre cada fila mostrando los datos hasta que se alcanzan todas las filas.
