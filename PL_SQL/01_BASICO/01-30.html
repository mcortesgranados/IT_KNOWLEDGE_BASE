Punto 01-30: Introducción a las Transacciones

En SQL, una transacción es un conjunto de operaciones que se ejecutan como una única unidad. La gestión de transacciones asegura que los datos se mantengan en un estado consistente, incluso en presencia de errores o fallos. Los dos conceptos clave en las transacciones son COMMIT y ROLLBACK.

Conceptos Clave:

  • COMMIT: Finaliza una transacción, guardando todos los cambios realizados en la base de datos. Una vez ejecutado, los cambios son permanentes y visibles para otras transacciones.
  • ROLLBACK: Revierte todos los cambios realizados durante una transacción, devolviendo la base de datos a su estado previo al inicio de la transacción. Se utiliza para deshacer cambios en caso de errores o inconsistencias.

Ejemplo de Uso de COMMIT y ROLLBACK

A continuación se muestra un ejemplo de cómo utilizar COMMIT y ROLLBACK en una transacción SQL:

BEGIN
    -- Iniciar la transacción
    UPDATE empleados SET salario = salario * 1.1 WHERE departamento = 'Ventas';
    -- Confirmar los cambios
    COMMIT;
EXCEPTION
    WHEN OTHERS THEN
        -- Deshacer los cambios en caso de error
        ROLLBACK;
END;
/

En este ejemplo, se inicia una transacción que actualiza los salarios de los empleados en el departamento de 'Ventas'. Si todo se ejecuta correctamente, se confirma la transacción con COMMIT. Si ocurre algún error, la transacción se revierte utilizando ROLLBACK, deshaciendo todos los cambios realizados.

Explicación de Introducción a las Transacciones: COMMIT: Utilizado para confirmar y guardar los cambios realizados en la base de datos durante una transacción. Es una operación irreversible que asegura que los cambios sean permanentes. ROLLBACK: Utilizado para revertir todos los cambios realizados durante una transacción en caso de errores. Devuelve la base de datos a su estado anterior al inicio de la transacción.
