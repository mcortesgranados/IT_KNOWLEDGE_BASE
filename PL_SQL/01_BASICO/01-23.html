Punto 01-23: Comentarios en PL/SQL

En PL/SQL, los comentarios son una herramienta importante para documentar el código y mejorar su legibilidad. Hay dos tipos principales de comentarios que se pueden usar:

  • Comentarios de Línea: Se utilizan para comentar una sola línea de código. Se representan con dos guiones consecutivos (--).
  • Comentarios de Bloque: Se utilizan para comentar múltiples líneas de código. Se encierran entre /* y */.

Ejemplo de Comentarios

A continuación se muestra un ejemplo de cómo utilizar ambos tipos de comentarios en PL/SQL:

DECLARE
    v_nombre VARCHAR2(50); -- Declaración de variable
BEGIN
    /* Este bloque de código
        asigna un valor a la variable
    y lo imprime en la consola. */
    v_nombre := 'Angela';
    DBMS_OUTPUT.PUT_LINE('Hola, ' || v_nombre);
END;
/

En este ejemplo, se usa un comentario de línea para describir la declaración de la variable v_nombre, y un comentario de bloque para describir el propósito del bloque de código que asigna un valor a la variable e imprime un saludo.

Explicación de Comentarios en PL/SQL: Comentarios de Línea (--): Utilizados para comentarios en una sola línea. Todo el texto después de los dos guiones es tratado como un comentario. Comentarios de Bloque (/* */): Utilizados para comentarios que abarcan varias líneas. El texto entre /* y */ es tratado como un comentario.
