Sentencias SELECT INTO en PL/SQL

La sentencia SELECT INTO en PL/SQL se utiliza para asignar los valores devueltos por una consulta a variables locales. Se utiliza cuando la consulta devuelve exactamente un registro.

Aquí tienes un ejemplo de cómo usar una sentencia SELECT INTO en PL/SQL:

DECLARE
    v_nombre EMPLOYEES.FIRST_NAME%TYPE;
    v_salario EMPLOYEES.SALARY%TYPE;
BEGIN
    SELECT FIRST_NAME, SALARY INTO v_nombre, v_salario
        FROM EMPLOYEES
        WHERE EMPLOYEE_ID = 100;

    DBMS_OUTPUT.PUT_LINE('Nombre: ' || v_nombre || ', Salario: ' || v_salario);
END;
/

Explicación:

  • Declaración: Se declaran dos variables v_nombre y v_salario que almacenarán el nombre y salario del empleado respectivamente.
  • SELECT INTO: Se realiza una consulta que selecciona el nombre y salario del empleado con EMPLOYEE_ID igual a 100. Estos valores se almacenan en las variables declaradas.
  • Salida: Se imprime el nombre y salario del empleado usando DBMS_OUTPUT.PUT_LINE.
Explicación de la sentencia SELECT INTO en PL/SQL: Sentencia SELECT INTO: Permite extraer valores de una consulta y almacenarlos directamente en variables declaradas en el bloque PL/SQL. Es importante que la consulta devuelva exactamente un registro, de lo contrario se generarán excepciones como NO_DATA_FOUND o TOO_MANY_ROWS. Ejemplo: Se recuperan los datos de un empleado con un EMPLOYEE_ID específico, y se almacenan en las variables para su posterior uso.
