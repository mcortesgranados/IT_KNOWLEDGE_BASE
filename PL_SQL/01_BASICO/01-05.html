Operadores Aritméticos en PL/SQL: Suma, Resta, Multiplicación y División

PL/SQL soporta los operadores aritméticos básicos:

  • Suma (+): Se utiliza para sumar dos valores.
  • Resta (-): Se utiliza para restar un valor de otro.
  • Multiplicación (*): Se utiliza para multiplicar dos valores.
  • División (/): Se utiliza para dividir un valor por otro.

A continuación se muestra un ejemplo básico de uso de estos operadores en PL/SQL:

DECLARE
    v_num1 NUMBER := 10;
    v_num2 NUMBER := 5;
    v_suma NUMBER;
    v_resta NUMBER;
    v_multiplicacion NUMBER;
    v_division NUMBER;
BEGIN
    v_suma := v_num1 + v_num2;
    v_resta := v_num1 - v_num2;
    v_multiplicacion := v_num1 * v_num2;
    v_division := v_num1 / v_num2;

    DBMS_OUTPUT.PUT_LINE('Suma: ' || v_suma);
    DBMS_OUTPUT.PUT_LINE('Resta: ' || v_resta);
    DBMS_OUTPUT.PUT_LINE('Multiplicación: ' || v_multiplicacion);
    DBMS_OUTPUT.PUT_LINE('División: ' || v_division);
END;
/

En este código:

  • Se declaran dos variables v_num1 y v_num2 con valores iniciales de 10 y 5, respectivamente.
  • Se utilizan operadores aritméticos para realizar cálculos y los resultados se almacenan en las variables v_suma, v_resta, v_multiplicacion, y v_division.
  • Los resultados se muestran utilizando DBMS_OUTPUT.PUT_LINE.
