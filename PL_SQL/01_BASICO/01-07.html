Sentencias IF-THEN-ELSE en PL/SQL: Condiciones Simples

La sentencia IF-THEN-ELSE en PL/SQL se utiliza para ejecutar diferentes bloques de código basados en el cumplimiento de una condición. Si la condición es verdadera, se ejecuta el bloque de código bajo el THEN; de lo contrario, se ejecuta el bloque bajo ELSE.

A continuación, se muestra un ejemplo básico de cómo usar IF-THEN-ELSE en PL/SQL:

DECLARE
    v_nota NUMBER := 85;
BEGIN
    IF v_nota >= 90 THEN
        DBMS_OUTPUT.PUT_LINE('Calificación: A');
    ELSIF v_nota >= 80 THEN
        DBMS_OUTPUT.PUT_LINE('Calificación: B');
    ELSE
        DBMS_OUTPUT.PUT_LINE('Calificación: C');
    END IF;
END;
/

En este código:

  • Se declara la variable v_nota con un valor de 85.
  • La sentencia IF-THEN-ELSE verifica el valor de v_nota y ejecuta diferentes bloques de código dependiendo de si la nota es mayor o igual a 90, entre 80 y 89, o menor que 80.
  • El resultado se muestra utilizando DBMS_OUTPUT.PUT_LINE.
