Excepciones Estándar en PL/SQL: NO_DATA_FOUND y TOO_MANY_ROWS

En PL/SQL, las excepciones estándar se utilizan para manejar errores comunes que pueden ocurrir durante la ejecución de una sentencia SQL. Las dos excepciones más comunes son:

  • NO_DATA_FOUND: Se lanza cuando una consulta SELECT INTO no devuelve ninguna fila.
  • TOO_MANY_ROWS: Se lanza cuando una consulta SELECT INTO devuelve más de una fila.

A continuación se muestra un ejemplo básico que maneja estas dos excepciones:

DECLARE
    v_nombre empleados.nombre%TYPE;
BEGIN
    -- Intentar recuperar el nombre de un empleado por ID
    SELECT nombre INTO v_nombre FROM empleados WHERE empleado_id = 101;
    DBMS_OUTPUT.PUT_LINE('Nombre del empleado: ' || v_nombre);
EXCEPTION
    WHEN NO_DATA_FOUND THEN
        DBMS_OUTPUT.PUT_LINE('No se encontró ningún empleado con ese ID.');
    WHEN TOO_MANY_ROWS THEN
        DBMS_OUTPUT.PUT_LINE('La consulta devolvió más de una fila.');
END;
/

En este código:

  • Intentamos seleccionar el nombre de un empleado cuyo ID es 101.
  • Si no se encuentra ningún empleado con ese ID, se lanza la excepción NO_DATA_FOUND y se maneja mostrando un mensaje apropiado.
  • Si la consulta devuelve más de una fila, se lanza la excepción TOO_MANY_ROWS y también se maneja mostrando un mensaje adecuado.
Explicación del código PL/SQL: Excepciones Estándar: NO_DATA_FOUND: Esta excepción ocurre cuando una consulta SELECT INTO no encuentra ninguna fila que coincida con los criterios de búsqueda. TOO_MANY_ROWS: Esta excepción se lanza cuando una consulta SELECT INTO devuelve más de una fila, lo cual no es permitido cuando usamos INTO para asignar resultados a una única variable. Código ejemplo: El bloque PL/SQL intenta recuperar el nombre de un empleado usando su ID. Dependiendo del resultado de la consulta, maneja las excepciones que pueden ocurrir si no se encuentra ningún empleado o si la consulta devuelve más de un resultado.
