Introducción a PL/SQL: Bloques Anónimos

Explicación

En PL/SQL, los bloques anónimos son bloques de código que se ejecutan sin estar almacenados previamente en la base de datos, a diferencia de los procedimientos o funciones que requieren ser almacenados y luego llamados. Un bloque PL/SQL anónimo no tiene nombre y se usa principalmente para ejecutar código temporal o para hacer pruebas.

Sintaxis Básica

DECLARE
  -- Declaración de variables (opcional)
BEGIN
  -- Código ejecutable
EXCEPTION
  -- Manejo de excepciones (opcional)
END;

Ejemplo de un Bloque PL/SQL Anónimo

DECLARE
    -- Declaración de variables
    v_salario NUMBER(7, 2) := 1000.00;
    v_bonificacion NUMBER(7, 2) := 200.00;
    v_total_salario NUMBER(7, 2);
BEGIN
    -- Cálculo del salario total
    v_total_salario := v_salario + v_bonificacion;
    
    -- Mostrar el resultado
    DBMS_OUTPUT.PUT_LINE('El salario total del empleado es: ' || v_total_salario);
EXCEPTION
    -- Manejo de excepciones en caso de error
    WHEN OTHERS THEN
        DBMS_OUTPUT.PUT_LINE('Ocurrió un error durante la ejecución.');
END;
/

Explicación del Código

DECLARE: Se declaran tres variables:

  • v_salario: Almacena el salario base del empleado.
  • v_bonificacion: Almacena la bonificación que se le añadirá al salario.
  • v_total_salario: Almacena el salario total después de sumar la bonificación.

BEGIN: Se realiza el cálculo sumando el salario base y la bonificación, luego se imprime el resultado utilizando el procedimiento DBMS_OUTPUT.PUT_LINE.

EXCEPTION: Si ocurre algún error durante la ejecución del bloque, el control se transfiere a esta sección y se imprime un mensaje de error.

END: Marca el final del bloque PL/SQL.
