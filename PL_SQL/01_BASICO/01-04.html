Asignación de valores en PL/SQL: Uso de :=

En PL/SQL, el operador := se usa para asignar un valor a una variable. Este operador asigna el valor de la expresión a la variable en el lado izquierdo del operador.

A continuación, se muestra un ejemplo básico:

DECLARE
    v_salario NUMBER(7,2);
BEGIN
    v_salario := 4500.50;
    DBMS_OUTPUT.PUT_LINE('El salario es: ' || v_salario);
END;
/

En este código:

  • Se declara una variable v_salario de tipo NUMBER.
  • La variable v_salario se inicializa con el valor 4500.50 utilizando el operador :=.
  • Se muestra el valor de la variable utilizando DBMS_OUTPUT.PUT_LINE.
