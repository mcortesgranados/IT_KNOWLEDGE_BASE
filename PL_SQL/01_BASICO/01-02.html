Estructura Básica de un Bloque PL/SQL

Explicación

La estructura básica de un bloque PL/SQL está compuesta por cuatro secciones clave:

  • DECLARE: (Opcional) Sección para declarar variables, cursores, constantes, excepciones y otros objetos PL/SQL.
  • BEGIN: (Obligatoria) Aquí se incluye el código ejecutable.
  • EXCEPTION: (Opcional) Sección para manejar excepciones (errores) que ocurran durante la ejecución del bloque.
  • END: (Obligatoria) Marca el final del bloque PL/SQL.

Sintaxis Básica

DECLARE
  -- Declaración de variables (opcional)
BEGIN
  -- Código ejecutable
EXCEPTION
  -- Manejo de excepciones (opcional)
END;

Ejemplo de un Bloque PL/SQL con Estructura Básica

DECLARE
    v_nombre VARCHAR2(50) := 'Angela';
    v_apellido VARCHAR2(50) := 'García';
BEGIN
    -- Imprimir nombre completo
    DBMS_OUTPUT.PUT_LINE('Nombre completo: ' || v_nombre || ' ' || v_apellido);
EXCEPTION
    -- Manejo de excepciones en caso de error
    WHEN OTHERS THEN
        DBMS_OUTPUT.PUT_LINE('Ocurrió un error durante la ejecución.');
END;
/

Explicación del Código

DECLARE: Se declaran dos variables:

  • v_nombre: Almacena el nombre de una persona.
  • v_apellido: Almacena el apellido de una persona.

BEGIN: Se utiliza DBMS_OUTPUT.PUT_LINE para concatenar y mostrar el nombre completo en la consola.

EXCEPTION: Si ocurre algún error durante la ejecución del bloque, se capturará y se imprimirá un mensaje de error.

END: Marca el final del bloque PL/SQL.
