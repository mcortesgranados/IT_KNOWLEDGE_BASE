Punto 01-26: Expresiones Booleanas

En PL/SQL, las expresiones booleanas son fundamentales para la lógica de control y las decisiones en el código. Las expresiones booleanas pueden ser verdaderas (TRUE), falsas (FALSE), o indeterminadas (NULL).

Valores Booleanos:

  • TRUE: Representa una condición verdadera.
  • FALSE: Representa una condición falsa.
  • NULL: Representa una condición indeterminada.

Ejemplo de Expresiones Booleanas

A continuación se muestra un ejemplo de cómo usar expresiones booleanas en una condición IF en PL/SQL:

DECLARE
    v_edad NUMBER := 25;
    es_adulto BOOLEAN;
BEGIN
    -- Evaluar si la persona es adulta
    IF v_edad >= 18 THEN
        es_adulto := TRUE;
    ELSE
        es_adulto := FALSE;
    END IF;
    IF es_adulto THEN
        DBMS_OUTPUT.PUT_LINE('La persona es adulta.');
    ELSE
        DBMS_OUTPUT.PUT_LINE('La persona no es adulta.');
    END IF;
END;
/

En este ejemplo, se evalúa si una persona es adulta basándose en su edad. La variable es_adulto se asigna como TRUE si la edad es mayor o igual a 18, y como FALSE en caso contrario. Luego, se imprime un mensaje dependiendo del valor de es_adulto.

Explicación de Expresiones Booleanas en PL/SQL: TRUE y FALSE: Son valores booleanos que representan condiciones verdaderas y falsas, respectivamente. Se usan en estructuras de control como IF y CASE. NULL: Representa una condición indeterminada. No es igual a TRUE ni FALSE, y se debe manejar específicamente para evitar errores en las evaluaciones lógicas.
