Funciones de Conversión en PL/SQL: TO_CHAR y TO_DATE

Las funciones TO_CHAR y TO_DATE son esenciales en PL/SQL para convertir entre cadenas de texto y valores de fecha o número.

Función TO_CHAR

La función TO_CHAR convierte un valor de fecha o número en una cadena de texto. Puedes especificar el formato de salida, lo que es muy útil para mostrar fechas de manera legible o para darle formato a números.

-- Convertir una fecha a formato de texto BEGIN
    DBMS_OUTPUT.PUT_LINE('Fecha formateada: ' || TO_CHAR(SYSDATE, 'DD-MON-YYYY HH24:MI:SS'));
END;
/

Este código convierte la fecha actual en una cadena con el formato DD-MON-YYYY HH24:MI:SS.

Función TO_DATE

La función TO_DATE convierte una cadena de texto en un valor de fecha, permitiendo especificar el formato de entrada. Esto es útil cuando necesitas procesar una fecha que se encuentra en formato de texto en tu código o base de datos.

-- Convertir una cadena a fecha DECLARE
    fecha DATE;
BEGIN
    fecha := TO_DATE('15-AUG-2024', 'DD-MON-YYYY');
    DBMS_OUTPUT.PUT_LINE('Fecha convertida: ' || TO_CHAR(fecha, 'DD/MM/YYYY'));
END;
/

En este ejemplo, una cadena de texto con el formato 15-AUG-2024 se convierte a un valor de fecha y se vuelve a mostrar en formato DD/MM/YYYY.

Uso Combinado

-- Convertir entre cadenas y fechas DECLARE
    cadena_fecha VARCHAR2(20) := '2024-08-15';
    fecha DATE;
BEGIN
    -- Convertir la cadena a una fecha
    fecha := TO_DATE(cadena_fecha, 'YYYY-MM-DD');
    -- Mostrar la fecha en un nuevo formato
    DBMS_OUTPUT.PUT_LINE('Fecha formateada: ' || TO_CHAR(fecha, 'DD-MON-YYYY'));
END;
/

Este código convierte una cadena de fecha en formato YYYY-MM-DD a una fecha real y luego la muestra en el formato DD-MON-YYYY.

Explicación de las Funciones de Conversión: TO_CHAR: Convierte valores de fecha o números a cadenas de texto, permitiendo especificar un formato de salida, como 'DD-MON-YYYY' o 'YYYY-MM-DD'. TO_DATE: Convierte una cadena de texto a un valor de fecha, permitiendo definir el formato de entrada, como 'DD-MON-YYYY' o 'YYYY-MM-DD'.
