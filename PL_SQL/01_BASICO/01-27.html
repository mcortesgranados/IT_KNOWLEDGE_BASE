Punto 01-27: Condiciones con CASE

En PL/SQL, la estructura CASE proporciona una forma alternativa a las sentencias IF-THEN-ELSE para realizar evaluaciones condicionales. Permite seleccionar entre múltiples valores posibles de manera más organizada.

Uso de CASE:

  • CASE Simple: Compara una expresión con varios valores posibles.
  • CASE de Búsqueda: Evalúa múltiples condiciones booleanas.

Ejemplo de Condiciones con CASE

A continuación se muestra un ejemplo de cómo usar la estructura CASE para evaluar una calificación y determinar el resultado correspondiente:

DECLARE
    v_calificacion NUMBER := 85;
    v_resultado VARCHAR2(20);
BEGIN
    -- Evaluar la calificación usando CASE
    v_resultado :=
        CASE
        WHEN v_calificacion >= 90 THEN 'Excelente'
        WHEN v_calificacion >= 80 THEN 'Bueno'
        WHEN v_calificacion >= 70 THEN 'Suficiente'
        ELSE 'Insuficiente'
    END CASE;
    DBMS_OUTPUT.PUT_LINE('Resultado: ' || v_resultado);
END;
/

En este ejemplo, se utiliza una expresión CASE para determinar el resultado basado en la calificación. Dependiendo del rango en el que se encuentra la calificación, se asigna un valor a v_resultado y se imprime el resultado.

Explicación de Condiciones con CASE en PL/SQL: CASE Simple: Compara una expresión con varios valores posibles, seleccionando el bloque de código que coincide con el valor. CASE de Búsqueda: Evalúa condiciones booleanas y ejecuta el bloque de código del primer caso que se cumple.
