Excepciones Personalizadas en PL/SQL: Uso de RAISE

En PL/SQL, además de las excepciones estándar, es posible definir y lanzar excepciones personalizadas usando la instrucción RAISE. Esto es útil cuando necesitas manejar situaciones específicas de tu aplicación.

Aquí tienes un ejemplo de cómo declarar y manejar una excepción personalizada:

DECLARE
    v_salario empleados.salario%TYPE := 5000;
    e_salario_bajo EXCEPTION;
BEGIN
    -- Comprobar si el salario es demasiado bajo
    IF v_salario < 10000 THEN
        RAISE e_salario_bajo;
    END IF;

    DBMS_OUTPUT.PUT_LINE('El salario es adecuado.');
EXCEPTION
    WHEN e_salario_bajo THEN
        DBMS_OUTPUT.PUT_LINE('Error: El salario es demasiado bajo.');
END;
/

En este código:

  • Se define una excepción personalizada llamada e_salario_bajo.
  • Si el salario es inferior a 10,000, se lanza la excepción usando RAISE e_salario_bajo.
  • La excepción es capturada en el bloque EXCEPTION, donde se maneja mostrando un mensaje de error.
Explicación del código PL/SQL: Excepciones Personalizadas: Puedes definir tus propias excepciones con el fin de manejar situaciones particulares que no estén cubiertas por las excepciones estándar. Para lanzar una excepción personalizada, usa la instrucción RAISE seguida del nombre de la excepción. Código Ejemplo: Se ha definido una excepción personalizada e_salario_bajo. Si el salario de un empleado es inferior a 10,000, se lanza la excepción personalizada. En la sección EXCEPTION, esta excepción es manejada y se imprime un mensaje indicando que el salario es demasiado bajo.
