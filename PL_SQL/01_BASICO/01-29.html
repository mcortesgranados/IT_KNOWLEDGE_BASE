Punto 01-29: Llamada a Funciones SQL

En SQL, las funciones agregadas como COUNT, SUM y AVG se utilizan para realizar cálculos sobre un conjunto de datos. Estas funciones permiten obtener información resumida y son fundamentales en la manipulación y análisis de datos.

Funciones SQL:

  • COUNT: Cuenta el número de filas que cumplen con una condición específica.
  • SUM: Suma los valores de una columna numérica.
  • AVG: Calcula el promedio de los valores de una columna numérica.

Ejemplo de Llamada a Funciones SQL

A continuación se muestra un ejemplo de cómo utilizar estas funciones en una consulta SQL:

SELECT
    COUNT(*) AS total_registros,
    SUM(salario) AS suma_salarios,
    AVG(salario) AS promedio_salario
FROM empleados;

En este ejemplo, se utilizan tres funciones:

  • COUNT(*): Cuenta el número total de registros en la tabla empleados.
  • SUM(salario): Calcula la suma total de los salarios en la tabla empleados.
  • AVG(salario): Calcula el promedio de los salarios en la tabla empleados.
Explicación de Llamada a Funciones SQL: COUNT: Esta función devuelve el número de filas que coinciden con la condición especificada. Se puede utilizar para contar todas las filas o las filas que cumplen ciertos criterios. SUM: Suma los valores de una columna numérica. Es útil para obtener el total acumulado de una columna. AVG: Calcula el promedio de los valores de una columna numérica. Permite determinar la media de un conjunto de datos.
