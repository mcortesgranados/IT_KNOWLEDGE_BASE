Bucles FOR en PL/SQL: Iteración un Número Determinado de Veces

El bucle FOR en PL/SQL permite repetir un bloque de código un número determinado de veces. Se utiliza para iterar sobre un rango de valores. Este tipo de bucle es útil cuando se sabe de antemano cuántas veces se debe ejecutar el código.

A continuación se muestra un ejemplo básico de cómo usar un bucle FOR en PL/SQL:

DECLARE
    v_i NUMBER;
BEGIN
    FOR v_i IN 1..5 LOOP
        DBMS_OUTPUT.PUT_LINE('Iteración número: ' || v_i);
    END LOOP;
END;
/

En este código:

  • El bucle FOR itera desde el valor 1 hasta el valor 5.
  • En cada iteración, el valor actual de v_i se imprime utilizando DBMS_OUTPUT.PUT_LINE.
  • El bucle se ejecutará exactamente 5 veces.
