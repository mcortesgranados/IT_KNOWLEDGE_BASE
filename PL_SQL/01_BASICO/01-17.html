Operaciones DML Básicas: INSERT, UPDATE y DELETE en PL/SQL

Las operaciones DML (Data Manipulation Language) son fundamentales para modificar los datos en las bases de datos. En PL/SQL, estas incluyen las sentencias INSERT, UPDATE y DELETE para insertar, actualizar y eliminar registros, respectivamente.

Aquí tienes ejemplos básicos de cada una de estas operaciones:

INSERT

BEGIN
    INSERT INTO EMPLOYEES (EMPLOYEE_ID, FIRST_NAME, LAST_NAME, SALARY)
    VALUES (101, 'John', 'Doe', 5000);
    COMMIT;
END;
/

Este código inserta un nuevo empleado en la tabla EMPLOYEES con el EMPLOYEE_ID 101 y un salario de 5000.

UPDATE

BEGIN
    UPDATE EMPLOYEES
    SET SALARY = SALARY * 1.1
    WHERE EMPLOYEE_ID = 101;
    COMMIT;
END;
/

Este código actualiza el salario del empleado con EMPLOYEE_ID 101, incrementándolo en un 10%.

DELETE

BEGIN
    DELETE FROM EMPLOYEES
    WHERE EMPLOYEE_ID = 101;
    COMMIT;
END;
/

Este código elimina el registro del empleado con EMPLOYEE_ID 101 de la tabla EMPLOYEES.

Explicación de las operaciones DML: INSERT: Inserta nuevos datos en una tabla. En el ejemplo, se inserta un nuevo empleado con EMPLOYEE_ID = 101. UPDATE: Modifica datos existentes en una tabla. En el ejemplo, se incrementa el salario de un empleado específico en un 10%. DELETE: Elimina datos de una tabla. En el ejemplo, se elimina el registro del empleado con EMPLOYEE_ID = 101.
