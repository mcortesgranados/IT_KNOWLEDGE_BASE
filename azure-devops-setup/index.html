Sign in to Microsoft Azure and pick your account

Part 1 · Account & portal

Everything starts from the Azure portal, since your Azure DevOps organization will be tied to the Microsoft identity (and, optionally, the subscription) you sign in with.

  1. Open a browser and go to https://portal.azure.com. The Microsoft sign-in page opens.
  2. On the “Pick an account” screen, click the account you want to use — in this example, veeduriabg@gmail.com (highlighted in red below).
  3. If your account is not listed, click Use another account and enter your credentials.

Step 1 — Pick the Microsoft account to continue to the Azure portal.

💡 Tip: Use the same account consistently throughout this guide. The Azure DevOps organization you create later will be created under the directory (tenant) of this sign-in.
2

Verify your identity — send a code to your email

Part 1 · Account & portal

Because you are signing in with a personal Microsoft account (such as one registered with a Gmail address), Microsoft asks you to prove your identity with a one-time verification code instead of a classic password prompt.

  1. After selecting your account, the “Get a code to sign in” screen appears, confirming the email the code will be sent to — in this example, veeduriabg@gmail.com.
  2. Click the Send code button (highlighted in red below).
  3. Microsoft emails a short one-time code to that address.
  4. On the next screen, open your email inbox, copy the code, paste/enter it into the verification field, and continue.

Step 2 — Click "Send code" to receive a one-time sign-in code by email.

💡 Tip: The code expires after a few minutes. If it doesn't arrive within a minute or two, check your spam/junk folder, then use the resend option on the verification screen.
3

Retrieve the single-use code from your inbox

Part 1 · Account & portal

Microsoft has emailed the verification code. Now switch to your email provider — in this example, Gmail — to fetch it. Since the sign-in used a Gmail address, the code arrives in the Gmail inbox.

  1. Open a new browser tab and go to https://mail.google.com, signed in with the same account you used for Azure (veeduriabg@gmail.com).
  2. In the inbox, locate the email from “Microsoft account team” with the subject “Your single-use code” (highlighted in red below) — it usually appears within seconds.
  3. Open it and copy the code shown in the body — in this example, 514944.
  4. Return to the Azure sign-in tab, enter the code in the verification field, and continue.
  5. If the email has not arrived after a minute or two, go back to the Azure tab, click resend and try again.

Step 3 — In Gmail, open the "Your single-use code" email from the Microsoft account team.

💡 Tip: The single-use code is valid for a limited time and works only once. Never share it with anyone — Microsoft will never ask you for it by phone or unsolicited email.
