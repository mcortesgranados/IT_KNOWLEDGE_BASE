Preguntas de TypeScript - Nivel Principiante

Set 1

1. ¿Qué es TypeScript?

TypeScript es un superconjunto tipado de JavaScript desarrollado por Microsoft que se compila a JavaScript puro.

2. ¿Cómo se instala TypeScript?

Se instala usando npm con el siguiente comando:

npm install -g typescript
3. ¿Cómo se compila un archivo TypeScript?

Se usa el compilador de TypeScript:

tsc archivo.ts
4. ¿Qué extensión tienen los archivos TypeScript?

La extensión es .ts.

5. ¿Cómo se define una variable con tipo en TypeScript? 
let nombre: string = "Angela";
6. ¿Qué es la inferencia de tipos en TypeScript?

Es la capacidad de TypeScript de deducir automáticamente el tipo de una variable sin necesidad de declararlo explícitamente.

7. ¿Cómo se define una función con tipos en TypeScript? 
function sumar(a: number, b: number): number {
    return a + b;
}
8. ¿Qué son los tipos primitivos en TypeScript?

Son string, number, boolean, null, undefined y symbol.

9. ¿Qué es una interfaz en TypeScript?

Una interfaz define la estructura de un objeto.

interface Persona {
    nombre: string;
    edad: number;
}
10. ¿Cómo se usa una interfaz en TypeScript? 
const usuario: Persona = {
    nombre: "Angela",
    edad: 30
};

Set 2

11. ¿Qué es un alias de tipo en TypeScript?

Es una forma de definir un nombre personalizado para un tipo.

type ID = string | number;
12. ¿Qué diferencia hay entre una interfaz y un alias de tipo?

Las interfaces pueden extenderse y combinarse, mientras que los alias de tipo son más flexibles para definir tipos complejos.

13. ¿Cómo se declara un array tipado en TypeScript? 
let numeros: number[] = [1, 2, 3, 4];
14. ¿Qué es una tupla en TypeScript?

Una tupla es un array con una cantidad fija de elementos con tipos específicos.

let usuario: [string, number] = ["Angela", 30];
15. ¿Cómo se define un tipo de objeto en TypeScript? 
let persona: { nombre: string; edad: number } = {
    nombre: "Angela",
    edad: 30
};
16. ¿Cómo se usa una función de tipo flecha en TypeScript? 
const sumar = (a: number, b: number): number => a + b;
17. ¿Qué es el tipo any en TypeScript?

El tipo any permite que una variable pueda contener cualquier tipo de dato.

18. ¿Por qué es mejor evitar el uso de any?

Porque deshabilita la verificación de tipos, reduciendo las ventajas de TypeScript.

19. ¿Cómo se define una unión de tipos en TypeScript? 
let valor: string | number;
20. ¿Qué es un tipo literal en TypeScript?

Es un tipo que solo permite ciertos valores específicos.

type Direccion = "norte" | "sur" | "este" | "oeste";

Set 3

9. ¿Cómo se implementa un genérico en TypeScript? 
function identidad(valor: T): T {
    return valor;
}
10. ¿Qué es un Decorador en TypeScript?

Un decorador es una función que se aplica a una clase, método o propiedad para modificar su comportamiento.

function Log(target: any, propertyKey: string) {
    console.log(`Llamado: ${propertyKey}`);
}
11. ¿Cómo se configura TypeScript con un archivo tsconfig.json?

Se genera con el siguiente comando:

tsc --init
12. ¿Qué son los módulos en TypeScript?

Permiten dividir el código en archivos reutilizables.

export function saludar() {
    return "Hola";
}
import { saludar } from "./modulo";
13. ¿Cómo se define un tipo condicional en TypeScript? 
type EsString = T extends string ? "Sí" : "No";
14. ¿Qué es un mapped type en TypeScript? 
type Opcional = { [P in keyof T]?: T[P] };

Set 4

15. ¿Cómo se usa la palabra clave "readonly" en TypeScript?

Se usa para hacer propiedades de solo lectura en una interfaz o clase.

interface Persona {
    readonly nombre: string;
}
16. ¿Qué son los Enums en TypeScript?

Los Enums permiten definir un conjunto de constantes con nombres descriptivos.

enum Direccion {
    Arriba,
    Abajo,
    Izquierda,
    Derecha
}
17. ¿Cómo se define una función con valores opcionales en TypeScript? 
function saludo(nombre: string, edad?: number) {
    return edad ? `${nombre} tiene ${edad} años` : `Hola ${nombre}`;
}
18. ¿Qué es el tipo "never" en TypeScript?

Se usa para funciones que nunca devuelven un valor, como errores.

function error(mensaje: string): never {
    throw new Error(mensaje);
}
19. ¿Cómo se usa "Partial" en TypeScript?

20. ¿Qué hace "Pick" en TypeScript?

Permite seleccionar un subconjunto de propiedades de un tipo.

type DatosBasicos = Pick;

Set 5

23. ¿Cómo definir una variable con un tipo específico?

24. ¿Qué son los "Type Assertions" en TypeScript?

Permiten indicar a TypeScript el tipo de una variable.

25. ¿Qué hace "Exclude"?

Elimina los tipos de U del conjunto de T.

26. ¿Cómo usar "Infer" en TypeScript?

Permite extraer tipos dentro de una condicional.

type Resultado = Extraer>; // string

Elimina propiedades específicas de un tipo.

type Usuario = { nombre: string; edad: number; correo: string };
type UsuarioSinCorreo = Omit;
118. ¿Qué hace "Exclude" en TypeScript?

Elimina tipos de una unión.

type Tipo = "a" | "b" | "c";
type SoloA = Exclude; // "a"
119. ¿Qué hace "Extract" en TypeScript?

Extrae tipos comunes de una unión.

type Tipo = "a" | "b" | "c";
type SoloB = Extract; // "b"
120. ¿Qué hace "NonNullable" en TypeScript?

Elimina null y undefined de un tipo.

type Tipo = string | null | undefined;
type SinNulos = NonNullable; // string
