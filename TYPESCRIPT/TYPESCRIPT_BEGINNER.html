TypeScript Beginner Questions - Set 1

1. What is TypeScript?

Answer: TypeScript is a strongly typed superset of JavaScript that compiles to plain JavaScript.

2. How do you declare a variable in TypeScript?

Answer: You can use let, const, or var to declare variables.

let name: string = "Angela";
const age: number = 30;

3. What are the basic data types in TypeScript?

Answer: TypeScript includes string, number, boolean, array, tuple, enum, any, void, null, and undefined.

4. How do you define an array in TypeScript?

let numbers: number[] = [1, 2, 3, 4, 5];

5. What is a tuple in TypeScript?

let person: [string, number] = ["Alice", 25];

6. What is an enum in TypeScript?

enum Color { Red, Green, Blue }
let c: Color = Color.Green;

7. What is the difference between any and unknown in TypeScript?

Answer: any disables type checking, while unknown requires type checking before usage.

8. How do you define a function in TypeScript?

function greet(name: string): string {
    return "Hello, " + name;
}

9. What is a TypeScript interface?

interface Person {
    name: string;
    age: number;
}

10. What is type inference in TypeScript?

Answer: TypeScript automatically infers types when possible

TypeScript Beginner Questions - Set 2

11. What is the difference between let and const in TypeScript?

Answer: let allows reassignment while const does not allow reassignment after initialization.

12. How do you create a union type in TypeScript?

let id: string | number;
id = "123"; // valid
id = 123;   // valid

13. What is a type alias in TypeScript?

type Point = { x: number; y: number };
let p: Point = { x: 10, y: 20 };

14. How do you use an optional property in an interface?

interface User {
    name: string;
    age?: number;
}

15. How do you define a default parameter in a TypeScript function?

function greet(name: string = "Guest"): string {
    return "Hello, " + name;
}

16. What are readonly properties in TypeScript?

interface Car {
    readonly model: string;
}
let myCar: Car = { model: "Toyota" };
// myCar.model = "Honda"; // Error

17. How do you create an intersection type in TypeScript?

type Person = { name: string };
type Employee = { id: number };
type Worker = Person & Employee;
let worker: Worker = { name: "Alice", id: 123 };

18. What is a generic function in TypeScript?

function identity(arg: T): T {
    return arg;
}
console.log(identity("Hello"));

19. How do you create an async function in TypeScript?

async function fetchData(): Promise {
    return "Data fetched";
}

20. What is a never type in TypeScript?

function error(message: string): never {
    throw new Error(message);
}

26. How do you make a property optional in TypeScript?

    name: string;
    age?: number;

27. What is a mapped type in TypeScript?

type User = { name: string; age: number };

28. How do you create a conditional type in TypeScript?

29. How do you use the extends keyword in TypeScript?

    name: string;
}

30. What is a type guard in TypeScript?

function isString(value: any): value is string {
    return typeof value === "string";
}
console.log(isString("hello")); // true

40. What is a discriminated union in TypeScript?

type Shape =
    | { kind: "circle"; radius: number }
    | { kind: "square"; side: number };

function getArea(shape: Shape): number {
    if (shape.kind === "circle") {
        return Math.PI * shape.radius ** 2;
    } else {
        return shape.side ** 2;
    }
}
