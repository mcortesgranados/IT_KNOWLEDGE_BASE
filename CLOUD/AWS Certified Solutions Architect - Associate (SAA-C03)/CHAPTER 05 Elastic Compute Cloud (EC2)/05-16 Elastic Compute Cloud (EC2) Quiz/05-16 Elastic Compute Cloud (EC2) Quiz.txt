QUESTION 3

Which command uses your Access key ID, Secret access key, AWS Region, and Output format to set up your default profile in the AWS CLI?


aws s3 ls


aws configure set

CORRECT
aws configure


aws configure list

Sorry!
aws s3 ls is used to list available S3 buckets. aws configure uses your Access key ID, Secret access key, AWS Region, and Output format to set up the AWS CLI.

Correct Answer
aws configure uses your Access key ID, Secret access key, AWS Region, and Output format to set up the AWS CLI. The AWS CLI stores this information in a profile named default in the credentials file. By default, the information in this profile is used when you run an AWS CLI command that doesn't explicitly specify a profile. The option --profile can be used to define different profile settings. You can then invoke the profile when issuing commands. As an example, the following would list S3 buckets using the information stored in the prod profile: aws s3 ls --profile prod.
