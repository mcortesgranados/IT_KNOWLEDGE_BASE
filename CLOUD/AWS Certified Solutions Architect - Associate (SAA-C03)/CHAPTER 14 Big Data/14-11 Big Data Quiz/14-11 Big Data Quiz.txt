QUESTION 8

What AWS service allows you to run SQL queries against exabytes of unstructured data in Amazon S3 without needing to load or transform the data?


Amazon OpenSearch Service


Amazon Redshift Serverless


Amazon X-Ray

CORRECT
Amazon Redshift Spectrum

Sorry!
Amazon OpenSearch Service, formerly known as Amazon Elasticsearch Service, is a fully managed service provided by AWS for deploying, securing, and scaling the open-source OpenSearch search and analytics engine. It enables you to search, analyze, and visualize data in real-time, making it useful for various use cases, including log and event data analysis, full-text search, and monitoring. AWS manages the operational aspects, allowing you to focus on your data and applications. With this service, you must ingest and load the data into the clusters to analyze it, which does not meet the requirements.

Correct Answer
Redshift Spectrum allows you to directly run SQL queries against exabytes of unstructured data in Amazon S3. No loading or transformation is required, and you can use open data formats, including Avro, CSV, Grok, Parquet, and others. Redshift Spectrum automatically scales query compute capacity based on the data being retrieved, so queries against Amazon S3 run fast, regardless of data set size. Reference: Amazon Redshift Spectrum overview

QUESTION 9

_____ allows you to query Kinesis data streams and perform interactive data analytics.


Amazon DynamoDB Query API


Amazon Relational Database Service (RDS)


Amazon Redshift

CORRECT
Amazon Managed Service for Apache Flink (formerly Kinesis Data Analytics)

Sorry!
The Query API operation in Amazon DynamoDB is used to find items within DynamoDB tables, and is based on primary key values. You would want to use Amazon Managed Service for Apache Flink Studio (formerly known as Kinesis Data Analytics). Reference: https://aws.amazon.com/managed-service-apache-flink/faqs/

Correct Answer
Within Amazon Managed Service for Apache Flink Studio (formerly known as Kinesis Data Analytics), you can write code in the notebook in SQL, Python, or Scala to interact with your streaming data, with query response times in seconds. Reference: https://aws.amazon.com/managed-service-apache-flink/faqs/
