QUESTION 1

Which of the following statements about Application Load Balancers (ALBs) is true?


You can create only one rule per ALB listener.


By default, ALB listeners check for connection requests from clients on port 443.

CORRECT
Application Load Balancers can be configured to use static IPs by partnering with a Network Load Balancer.


ALB rules are evaluated in priority order, from the highest value to the lowest value.

Sorry!
ALB listeners do not listen to connection requests on port 443 by default, You must set up an HTTPS listener first. Reference Documentation: Create an HTTPS listener for your Application Load Balancer (https://docs.aws.amazon.com/elasticloadbalancing/latest/application/create-https-listener.html)

Correct Answer
In AWS, an Application Load Balancer (ALB) typically uses dynamic IP addressing. If you need your ALB to have a static IP address, you can achieve this by using a Network Load Balancer (NLB). You can associate the NLB with an Elastic IP address, which is a static, public IPv4 address, and then register your ALB as a target of the NLB. This setup effectively allows the ALB to use a static IP address, although it requires additional configuration and is not the default behavior of an ALB.
