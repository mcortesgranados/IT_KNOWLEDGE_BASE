QUESTION 5

What best describes "immutable pattern" for application code deployments?


Deployed application code can't destroy cloud resources.


Deployed application code requires your cloud architecture to be in read-only mode.

CORRECT
Deployed application code can't modify existing cloud resources, which, as a result, requires the creation of new resources.


Deployed application code can't proceed because AWS has locked your account.

Sorry!
This statement is not accurate. Immutable pattern can't modify (not destroy) existing cloud resources.

Correct Answer
The immutable pattern specifies a deployment of application code by starting an entirely new set of servers with a new configuration or version of application code. When we go immutable, we don't want to ever upgrade in place. Once the cloud resource exists, it can't be modified. Reference Documentation: Immutable and Blue/Green Deployment (https://docs.aws.amazon.com/whitepapers/latest/practicing-continuous-integration-continuous-delivery/immutable-and-bluegreen-deployment.html).

QUESTION 8

What is a primary use case for the AWS Systems Manager Parameter Store "SecureString" parameter?


For directly connecting to your EC2 instances.


For managing the patch level on your Windows servers.


For storing non-sensitive data that does not require encryption.

CORRECT
For sensitive data that needs to be stored and referenced in a secure manner.

Sorry!
The SecureString parameter is not used for managing patch levels. AWS Systems Manager does have a Patch Manager for managing patches on your servers.

Correct Answer
A SecureString parameter is any sensitive data that needs to be stored and referenced in a secure manner. If you have data that you don't want users to alter or reference in plaintext, such as passwords or license keys, create those parameters using the SecureString data type. Only the value of a SecureString parameter is encrypted. Parameter names, descriptions, and other properties aren't encrypted. Reference Documentation: AWS Systems Manager Parameter Store (https://docs.aws.amazon.com/systems-manager/latest/userguide/systems-manager-parameter-store.html)
