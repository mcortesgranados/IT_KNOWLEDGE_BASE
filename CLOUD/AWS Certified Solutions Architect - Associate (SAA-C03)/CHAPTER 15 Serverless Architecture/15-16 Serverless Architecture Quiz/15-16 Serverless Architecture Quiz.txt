QUESTION 1

Which service is an AWS-managed repository for custom Docker images?


AWS Docker Hub


AWS Lambda Layers


Amazon Elastic Container Service (Amazon ECS)

CORRECT
Amazon Elastic Container Registry (Amazon ECR)

Sorry!
AWS Docker Hub is not a real service.

Correct Answer
Amazon Elastic Container Registry (Amazon ECR) is an AWS-managed container image registry service that is secure, scalable, and reliable. You can store Docker images, Open Container Initiative (OCI) images, and OCI-compatible artifacts.

QUESTION 10

Amazon RDS


DynamoDB

CORRECT

Sorry!

Correct Answer
