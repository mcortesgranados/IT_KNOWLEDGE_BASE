QUESTION 2

Which statement best describes an Availability Zone?

CORRECT
One or more discrete data centers with redundant power, networking, and connectivity in an AWS Region.


A physical data center that is connected to AWS cloud services.


A single data center that makes up an Edge location.


A collection of EC2 instances that is guaranteed not to fail.

Good work!
An Availability Zone (AZ) is one or more discrete data centers with redundant power, networking, and connectivity in an AWS Region. AZs are physically separated by a meaningful distance, many kilometers, from any other AZ, although all are within 100 km (60 miles) of each other. Reference Documentation: Regions and Availability Zones
