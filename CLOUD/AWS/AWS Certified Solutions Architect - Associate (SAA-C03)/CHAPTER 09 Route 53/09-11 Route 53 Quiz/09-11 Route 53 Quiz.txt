QUESTION 1

Which of the following statements about Route 53 failover policies is true?

CORRECT
With DNS failover, if a record set fails a health check, it will be removed from the Route 53 response until it passes the health check.


With DNS failover, if a record set fails a security check, it will be removed from the Route 53 response until it passes the security check.


With DNS failover, if a record set fails a security check, it will be removed from the Route 53 response until the owner adds it again.


With DNS failover, if a record set fails a health check, it will be removed from the Route 53 response until the owner adds it again.

Good work!
DNS Failover consists of two components: health checks and failover. Health checks are automated requests sent over the Internet to your application to verify that your application is reachable, available, and functional. With DNS failover, if a record set fails a health check, it will be removed from the Route 53 response until it passes the health check. Health Checks & DNS Failover.

QUESTION 5

Using Route 53, how would you direct "example.com" to an ELB?


By creating an AAAA record


By creating a TXT record

CORRECT
By creating an alias record


By creating a CNAME

Sorry!
An AAAA record, or IPv6 Address record, is a type of DNS record that points a domain name to an IPv6 address. It is used to enable IPv6 connectivity for websites and other services.

Correct Answer
An AWS DNS alias record is a type of record that points a domain name to an AWS resource, such as an Elastic Beanstalk environment, an Amazon CloudFront distribution, or an Amazon S3 bucket. It is used to create subdomains or point a domain name to a different AWS service. Reference: Values for Alias Records (https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/resource-record-sets-values-alias.html)
