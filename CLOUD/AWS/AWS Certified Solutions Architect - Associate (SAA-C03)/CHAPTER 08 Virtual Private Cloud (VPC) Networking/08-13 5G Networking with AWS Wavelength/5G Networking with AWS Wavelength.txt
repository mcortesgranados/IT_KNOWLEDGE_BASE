So what does this have to do with AWS?
Well, AWS have a new service called AWS Wavelength,
and this embeds AWS compute and storage services
within 5G networks,
basically providing a mobile edge computing infrastructure
which allows you to develop and deploy
and scale ultra-low-latency applications.
So how does this work?
Well, let's say you've got an application in your car.
Maybe you're designing some kind
of new smart car like Tesla.
And you want to be able to do some compute or storage
at edge using 5G.
Well, basically this is how it works.
The car will communicate to the 5G network,
and there'll be an actual AWS device
within that network tower,
and it will be doing the computing and the storage at edge,
and then it will be communicating back to your car,
and then of course the 5G network will also then transfer
that data across to AWS, depending on how you architect it.
So that's all it is.
