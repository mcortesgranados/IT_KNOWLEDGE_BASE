So what is Security Hub?
Well, basically it's a single place to view
all your security alerts from services
like Amazon Guard Duty,
Amazon Inspector, Amazon Macie, and AWS Firewall Manager,
and it works across multiple accounts.
So this is just a single pane of glass
to see what's going on
with all your different security alerts
across multiple AWS accounts.
That's all it is.
So you can conduct Cloud Security Posture Management,
or CSPM,
and this is basically using automated checks
that comply with common frameworks
such as the Center for Information Security,
PCI DSS, etc.
And you can also correlate security findings
to discover new insights.
You can aggregate all your findings in one place
allowing your security staff
to more easily identify threats and alerts.
